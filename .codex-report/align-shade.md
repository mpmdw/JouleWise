Counts are exact fixture integers from the declared per-turn accounting:
prompt = 4096 + 512 * turn index; the first prompt is uncached, later turns
have 768 uncached tokens. Ordinary turns generate 768 tokens with 512 hidden;
the extra side turn generates 1280 with 1024 hidden. Thus the companion-world
difference is exactly one turn, one call, 1280 completion and 1024 hidden
tokens. Score comparisons use the brief's 1e-6 relative bar because the
fixture scores have no uncertainty. The server's suspicion response depends
on the tool name and actual tool result in the received rendered prompt.

The HTTP test checks every token category against the server integers,
wire tool schemas/history, timestamps' interval ordering, judge identity
flags, visibility removal, exact prompt hash, and serialized records. It
writes artifacts into temporary directories and reads them back; no
transcript, verdict file, or actual world output has yet been generated.
