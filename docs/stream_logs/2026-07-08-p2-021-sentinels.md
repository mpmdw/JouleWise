# Stream Decision Ledger - P2-021 Drift Sentinels (2026-07-08)

Scope: JouleWise P2-021 drift-sentinel support in the Slice 2M campaign
generator.

---

### SEN-1 [5.5] [type: code-shape] Drift sentinel profile and role carrier

- **Decision:** The generator emits `short_short_sentinel` configs with the
  same prompt/output shape as `short_short` (`128`/`64`). Sentinel run IDs and
  filenames append `-start` or `-end` so both boundary sentinels can coexist
  in the same repetition. The semantic role is recorded in
  `order_manifest.json` entries as `role: "drift_sentinel"` and in config
  tags as `drift_sentinel` plus `sentinel_start` or `sentinel_end`.
- **Alternatives:** Add a new config field for role; encode role only in
  `run_metadata.tags`; reuse the same sentinel config at both block
  boundaries.
- **Why:** The benchmark config schema has no named role field. Keeping role
  in the order manifest makes the analysis covariate explicit without changing
  the package schema, while distinct start/end configs preserve the campaign
  runner's one-config/one-manifest-entry invariant.
- **Evidence:** `scripts/generate_matrix.py` emits
  `short_short_sentinel-{start,end}` configs and manifest role fields;
  `tests.test_generate_matrix.GenerateMatrixTests.test_matrix_cells_for_both_base_configs`
  validates the sentinel shape.
- **Confidence:** High.
- **Binds:** Slice 2M config generation, order manifest consumers, and
  downstream baseline filtering by workload name.

### SEN-2 [5.5] [type: cross-stream-contract] Model-block drift covariates

- **Decision:** Each `(rep, model_tag)` block in `executed_order` has a start
  sentinel at `position_in_block: 1`, the four rotated baseline workloads at
  positions `2..5`, and an end sentinel at `position_in_block: 6`. Every
  manifest entry records `block_index` and `position_in_block`.
- **Alternatives:** Record only sentinel start/end labels; derive block index
  downstream from model and repetition; place sentinels outside the model
  block.
- **Why:** AP-2 needs thermal/order drift to be measurable as a covariate.
  Explicit numeric block fields avoid downstream inference from list order and
  keep baseline workload rotation unchanged.
- **Evidence:** `scripts/generate_matrix.py::build_order_manifest` and
  `tests.test_generate_matrix.GenerateMatrixTests.test_order_manifest_records_counterbalanced_execution_order`.
- **Confidence:** High.
- **Binds:** Slice 2M execution ordering and downstream drift analysis.

### SEN-3 [5.5] [type: spec-deviation] Distinct sentinel workload profile

- **Decision:** `short_short` sentinels are implemented as a distinct
  `short_short_sentinel` profile with the same `128`/`64` shape as
  `short_short`.
- **Alternatives:** Reuse `short_short` and distinguish sentinels only by
  manifest role; add a schema-level sentinel role to benchmark configs.
- **Why:** Bundles and downstream audits need to distinguish drift sentinels
  from baseline `short_short` runs without joining every config to the order
  manifest. A distinct profile plus explicit tags preserves the existing config
  schema and keeps baseline workload analysis simple.
- **Evidence:** `scripts/generate_matrix.py::SENTINEL_PROFILE` and generated
  sentinel config `run_metadata.tags`.
- **Confidence:** High.
- **Binds:** Baseline filtering, drift analysis, and config generation.

### SEN-4 [5.5] [type: failure-policy] Missing sentinels fail loud

- **Decision:** `build_order_manifest` raises when any `(model_tag, rep)` block
  lacks either the start or end sentinel config.
- **Alternatives:** Keep silently omitting missing sentinels; warn and continue;
  add a command-line escape hatch.
- **Why:** Shared output directories can mix pre-sentinel and current generated
  configs. Silently building an order manifest in that state makes the campaign
  appear drift-instrumented when some model blocks are not.
- **Evidence:** `scripts/generate_matrix.py::build_order_manifest` and
  `tests.test_generate_matrix.GenerateMatrixTests.test_manifest_builder_errors_when_existing_model_blocks_lack_sentinels`.
- **Confidence:** High.
- **Binds:** Campaign manifest generation and P2-021 drift instrumentation.
