# Advisor tabs + brief copy-through ledger (2026-07-17)

Scope: add one-click Advisor Brief and PROJECT_STATUS tabs to the generated
site, preserve the self-contained advisor brief, regenerate the Lakebed
capsule without deployment, and retain the conservative size guards.

## Decisions

### AUD-WO-039 right-sizing review — D-076-pending

Lead ruling (recorded verbatim):

> Ed directed hosting the advisor brief in-capsule ("one central location") — this IS the site-capacity decision event. Therefore: (a) the 1 MiB Lakebed HARD CAP is inviolate; (b) soft budgets move to MEASURED-mode reality: measured-artifact budget raises to 1,000,000 B (leaves >=48 KB margin), and the conservative-ESTIMATE guard applies ONLY when measured mode is unavailable, with the estimator overshoot documented (est 1,001,328 vs measured 960,030 on identical input, ~4.3%); (c) WO-039 boundary holds: trim only proven-unused payload if any is found, preserve all advisor-facing pages/navigation/provenance; (d) postconditions stay LOUD (SITE-02 discovery discipline).

Disposition: the brief, every existing advisor-facing page, navigation, stable
deep link, source route, and provenance record are retained. No proven-unused
payload was found in this bounded change, so none was removed. The packer uses
the measured budget only after discovering and version-checking Lakebed
0.0.29; the conservative estimator remains the loud fallback-only guard.

### ST-001 — Keep the advisor brief byte-preserving

- `docs/advisor_briefs/2026-07-17-window-a-brief.html` is copied to
  `advisor_brief.html` by the generator.
- The generated file contains one non-rendering provenance comment followed by
  the source bytes verbatim. The brief does not pass through the site shell,
  Markdown renderer, stylesheet, or generated-HTML compactor.
- The capsule server suppresses its normal runtime freshness injection for the
  canonical brief page so the served HTML remains the generated copy-through.
- The ordinary generated shell pages all link to the brief. The brief itself is
  intentionally not given the site shell because doing so would contradict the
  verbatim-copy requirement.

### ST-002 — Make PROJECT_STATUS the visible Status tab

- `Status` links directly to `project_status.html`, which is still generated
  from `PROJECT_STATUS.md` and now marks that tab active.
- The existing generated status observatory remains reachable as `Live Status`
  at `status.html`; no existing route is removed.
- Navigation order is Project, Learn, Advisor Brief, Status, Live Status,
  Roadmap, Process, Record, Sources, Measurements.

### ST-003 — Minify generated formatting, never content

- Non-brief generated HTML collapses ordinary formatting whitespace while
  preserving `pre`, `code`, `script`, `style`, and `textarea` blocks exactly.
- This is sufficient to keep every individual page under the existing 30,000
  base64-byte runtime shard budget. It does not alter prose, source documents,
  the brief, or either capsule guard.

### ST-004 — SUPERSEDED: stop rather than evade the capsule guard

- Attempt 1 correctly stopped because the then-controlling tests applied the
  943,718-byte conservative estimate budget and the stricter 920,000-byte
  integration-headroom assertion even when a real measurement existed.
- The remaining reduction cannot be obtained by whitespace minification of
  the already-minified `docs/site_src` assets. Meeting 920,000 requires about
  26,142 fewer packed-content bytes; the complete authored source assets are
  only 45,334 raw bytes and their generated CSS is already minified.
- No route, prose, source access, provenance, or guard was removed or weakened.
  The lead has now supplied the required retained-route/value and capacity
  review above; ST-005 implements it.

### ST-005 — Explicit verbatim routes and measured-first capacity

- `PageMode.VERBATIM` is a first-class packer model. The advisor brief declares
  its configured provenance source, bypasses generated-page stylesheet/source
  sentinels and href rewriting, and carries `verbatim: true` in the emitted
  route manifest.
- The server suppresses shared freshness injection from the route metadata,
  not from a hard-coded path sentinel. The generated page (provenance comment
  plus source bytes) is therefore served unchanged.
- Exact-version measured mode enforces a 1,000,000 B artifact budget and the
  inviolate 1,048,576 B hard cap. Only unavailable measured mode invokes the
  conservative 943,718 B estimator guard; wrong-version or failed measured
  builds still refuse loudly with no fallback.
- Generated shell pages expose `Advisor Brief`, `Status` (the
  `PROJECT_STATUS.md` page), and retained `Live Status` navigation. The
  self-contained brief itself remains verbatim and therefore does not acquire
  the generated shell.
