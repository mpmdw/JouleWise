## [orchestrator] Scope and seams inherited (context, not yet a decision)

The stream implements Slice 2K per `hardware_slice_implementation_guide.md`
§2K and pins the wire-level protocol into
`docs/contracts/node_worker_protocol.md`. Key inherited facts the design must
respect:

- Registry seam (`joulewise/adapters/__init__.py`): `resolve_runtime` /
  `resolve_telemetry` / `resolve_transport` each return `(adapter, None)` or
  `(None, AdapterResult failure)`; never raise. New backends land behind lazy
  imports (D-009). Enums already exist: `TransportKind.SSH`,
  `RuntimeBackend.VLLM`, `TelemetryBackend.NVIDIA_SMI`; schema already requires
  `hardware_target.host` when transport is ssh.
- Controller lifecycle (`controller.py`) is fixed and shared. It resolves
  transport, runtime, telemetry independently and drives: prepare →
  idle_baseline → warmup → measured_run (thermal_pre, start_sampling,
  run_workload, stop_sampling, thermal_post) → cleanup → reduce. The controller
  does NOT currently pass the transport into runtime/telemetry adapter methods
  — the remote runtime and telemetry adapters need transport access by some
  other seam. **This is the central seam-placement question for the design
  round.**
- RunContext (D-024) carries config, clock, run_id, paths (raw_dir, logs_dir,
  outputs_dir), node_role. Raw evidence lands under `context.raw_dir` via
  `joulewise.bundle.write_raw_artifact` (adapters never write raw/ directly).
- D-026 measured-window markers: `start_sampling` returns only when sampling is
  confirmed active; stop-side parsing happens inside `stop_sampling`. Spawn
  latency and wind-down must stay outside the window.
- Structured failure taxonomy (D-012): unsupported (finding) =
  runtime_unavailable / telemetry_unavailable / did_not_fit;
  failed (operational) = permission_denied / transport_unavailable /
  unknown_error. Registry maps unreachable/unavailable to the right code.
- Style references: `mlx_runtime.py` (runtime event taxonomy: prefill/decode
  phases, `phase_boundary_method: first_token`, token events, response.txt +
  tokens.jsonl), `powermetrics.py` (raw-first sampler, readiness wait,
  rail_manifest, clock-anchored timestamps).

Schema changes additive-only (R-015). Shared-file edits minimized; another
stream edits joulewise core concurrently.
