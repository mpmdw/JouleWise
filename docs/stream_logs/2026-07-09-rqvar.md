## P34-2 [codex S10] [type: estimand] Natural EOS is the primary distribution

- **Decision:** The primary estimand is the natural sampled request-energy
  distribution under a named sampler, with an administrative safety cap treated
  as censoring. A fixed-cap distribution is allowed only if named as a capped
  policy estimand.
- **Alternatives:** Use fixed capped generation as the main study; discard
  cap-hit rows.
- **Why:** The question is whether sampling can produce a lucky short reasoning
  path. A fixed cap truncates the long tail and changes the answer. Discarding
  capped rows would hide the tail failure.
- **Evidence:** Design sections "Estimands" and "Replay-Decomposition
  Protocol".
- **Confidence:** High.
- **Binds:** Stop-reason and cap-hit audit are required for any tail wording.

## P34-3 [codex S10] [type: instrumentation] Replay is exact emitted-token IDs

- **Decision:** Phase B replay must use recorded emitted output token IDs as
  the replay script, not response text retokenization. Forced-token replay is
  named as a missing harness gap.
- **Alternatives:** Re-run with the same seed; replay text responses; rely on
  greedy prompt-cache replay evidence alone.
- **Why:** Same seed can drift when sampler/runtime state changes; text replay
  loses token identity; Stage 3.0.1 establishes same-stack replay feasibility
  but not forced sampled-output replay.
- **Evidence:** Design sections "Phase B" and "Harness support today".
- **Confidence:** High.
- **Binds:** `G-RQVAR-FORCED-IDS` and `G-RQVAR-REPLAY-MANIFEST` should be
  closed before claim-bearing execution.

## P34-4 [codex S10] [type: statistics] Extremes-only replay is diagnostic

- **Decision:** Shortest/median/longest replay is retained as a minimal
  diagnostic, but a credible decomposition requires at least quantile-stratified
  replay, and fuller decomposition uses decile-stratified replay.
- **Alternatives:** Estimate the between-path variance component from only the
  shortest, median, and longest paths.
- **Why:** Extremes selected after Phase A are order statistics. They are valid
  realized paths but biased as a basis for average residual variance.
- **Evidence:** Design section "Selection rule".
- **Confidence:** Medium-high.
- **Binds:** Future reports must not call the three-path diagnostic a full
  variance decomposition.

## P34-6 [codex S10] [type: feasibility] Minimal credible version sized at 134 bundles

- **Decision:** The minimal credible one-cell design is `N = 80` sampled
  Phase-A bundles plus `9 x 6 = 54` replay bundles, total 134 bundles before a
  10% replacement buffer.
- **Alternatives:** Stop at `N = 30` or `N = 50`; run `N = 100` plus
  decile-stratified replay as the only acceptable design.
- **Why:** `N = 80` is the first practical point where P90/P10 order-statistic
  intervals are not purely top-few-observation evidence, while still fitting
  the observed 30-75 bundle/hour throughput. `N = 100` is better but not
  necessary for a first credible one-cell campaign.
- **Evidence:** Design sections "N sizing" and "Feasibility".
- **Confidence:** Medium.
- **Binds:** Lead should double-check whether the first promoted run wants
  `N = 80` or `N = 100`.

## P34-7 [codex FH2] [type: review-fix] FH2 SHOULD-FIX dispositions applied

- **Decision:** Accepted both FH2 reviewer findings. Claim-bearing replay
  decomposition now requires either random Phase-A path selection or
  decile-stratified random selection with explicit `W_d = M_d / M` weights and a
  declared empirical Phase-A path-distribution estimand. The deterministic
  nine-landmark quantile path set is relabeled as a diagnostic/approximation,
  not a minimal credible decomposition.
- **Decision:** Split the top-up rule. Phase-A `N` top-up to 100 is allowed only
  for P90/P10 CI width. Excess cap hits are a censoring/policy problem: the cap
  must be raised/redeclared under the predeclared policy with compatible
  rerun/augmentation, or the wording must downgrade to capped-policy/censored.
  Larger `N` at the same cap is no longer presented as a cure.
- **Alternatives:** Keep the nine quantile/extreme paths as the minimal credible
  decomposition; treat cap-hit excess as another reason to sample more at the
  same administrative cap.
- **Why:** Deterministic length quantiles do not define inclusion probabilities
  for the empirical path distribution, and additional censored draws cannot
  recover the natural-EOS upper tail.
- **Evidence:** FH2 reviewer report
  `/private/tmp/claude-501/-Users-edr-code-JouleWise/76b483dd-64da-4113-bb7e-9f847179fcbc/scratchpad/FH2-rqvar.md`
  and `docs/specs/rq_energy_variance_design.md`.
- **Confidence:** High.
- **Binds:** This supersedes P34-4's older "quantile-stratified replay" wording
  for claim-bearing decomposition; future AP promotion must carry the random or
  weighted stratified selection design.
