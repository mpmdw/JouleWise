# `_v5` artifact flow: collection to paper claim gate

Use the variable names from the [G2 runsheet](../process_traces/2026-08-28-live-smoke/SHAKEDOWN-G2-RUNSHEET.md). *G2-a* is the preliminary input-length trial; a *rung* is one candidate token length; a *pack* is the closed set of plans and run configurations; a *bundle* is one immutable run directory; *strict validation* rebuilds its stored numbers from raw files; *reduction* writes that rebuild outside the bundle; a *floor* is the smallest false effect the instrument can create; a *mint* is the authenticated floor artifact; the *claim gate* is the final code path that decides whether a paper claim is supported; a *member* is one run inside a stage; a *stage* (or *half-stage*) is one generated ordered list of members that the collector runs as a unit; a *manifest* is a JSON record that names other files by content hash; *preflight* is the collector's pre-launch config check; *launch authentication* is its proof that the config on disk is the frozen one; a *pre-calibration* is the instrument calibration captured just before a stage; the *whole-window verdict* is the machine-quiet check over the entire collection interval; a *pinset* is the list of content hashes a mint may consume; *custody* is the append-only directory where authenticated artifacts are stored; an *evidence root* is a named directory of immutable run bundles; and the *calibration ledger* is the append-only record of every calibration capture.
