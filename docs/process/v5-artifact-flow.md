# `_v5` artifact flow: collection to paper claim gate

Use the variable names from the [G2 runsheet](../process_traces/2026-08-28-live-smoke/SHAKEDOWN-G2-RUNSHEET.md). *G2-a* is the preliminary input-length trial; a *rung* is one candidate token length; a *pack* is the closed set of plans and run configurations; a *bundle* is one immutable run directory; **Strict validation** proves a stored summary follows from raw evidence; **Reduction** rebuilds the summary without changing the bundle; a *floor* is the smallest false effect the instrument can create; a *mint* is the authenticated floor artifact; **Finalization** binds post-collection identities without reading an effect estimate; the *claim gate* is the final code path that decides whether a paper claim is supported; a *member* is one run inside a stage; a *stage* is one generated ordered list of members that the collector runs as a unit; a *manifest* is a JSON record that names other files by content hash; *preflight* is the collector's pre-launch config check; *launch authentication* is its proof that the config on disk is the frozen one; a *pre-calibration* is the instrument calibration captured just before a stage; a *whole-window verdict* is the machine-quiet check over the entire collection interval; a *pinset* is the list of content hashes a mint may consume; *custody* is the append-only directory where authenticated artifacts are stored; an *evidence root* is a named directory of immutable run bundles; and the *calibration ledger* is the append-only record of every calibration capture.

This table is the command and artifact map. The L10 row is the three-part
ladder in the [L10 rehearsal phase](v5-l10-rehearsal-phase.md); its commands
retain the owner modules shown here.
