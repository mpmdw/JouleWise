Feasibility verdict · Phase 3

A saved thought resumes exactly.

Split inference needs the model's working memory — the KV cache — to survive a save, a process boundary, and a reload. The Stage 3.0.1 spike proved it on this hardware: prefill in one OS process, save to disk, resume decoding in a fresh process, and compare against an unbroken run.

Verdict: 64 of 64 decode tokens identical at both tested prompt lengths, zero divergence — and the analytic cache-size model predicted the on-disk size to within a constant 5.3 KiB header.
