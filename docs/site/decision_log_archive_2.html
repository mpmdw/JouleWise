Decision Log

This is the canonical record of design decisions for JouleWise. Every decision that binds later work, trades off real alternatives, or would otherwise need to be re-derived by a future agent gets an entry here.

How To Use This Log

  • Before implementing anything non-trivial, check whether a decision here already covers it. Do not silently re-decide settled questions.
  • When you make a new decision of this kind during a run, add an entry, link it from the run report, and reference its ID (D-NNN) in the code review or doc that applies it.
  • Statuses: accepted (binding until revisited), open (criteria defined, evidence pending), proposed (recorded, awaiting Ed's ratification), superseded by D-NNN.
  • Every entry must include Options Considered and Considerations. A decision without recorded alternatives is not auditable.
  • Revisit triggers are part of the contract: when a trigger fires, the decision must be re-examined, not quietly worked around.
