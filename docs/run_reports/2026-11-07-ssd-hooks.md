Enrollment binds serial, bus/service path, disk UUID when exposed, all partition,
APFS container and volume UUIDs, and the enrollment entry ID. Device names may
renumber between windows; stable identity must still match, and a window's entry
ID must match its unmount/arm snapshot. Census joins physical-store and
synthesized APFS nodes, reads every `AllDisks` entry and traces mounted internal
APFS volumes back to physical storage so a virtual disk image cannot pass on
an `Internal` flag alone. Unknown evidence refuses.

Unmount uses the APFS-store **partition UUID**, never `force`. It verifies all
device children unmounted and samples counters twice, starting Q at the second
stable sample. Snapshot receipts bind the config digest, boot session and
monotonic time; raw diagnostic snapshots cannot establish Q. The default retry
count follows operative §3.4 (one retry), rather than §3.2's three-retry negative
qualification example. This discrepancy is disclosed rather than changing the
agreement; the retry value is configurable.

Offload requires a caller-authored `joulewise.ssd_closed_record.v1` manifest,
exact file inventory and all SHA-256 digests before mounting. It rejects links,
special files, unsafe paths and writes to empty mountpoints. Writes use a pinned
filesystem descriptor, exclusive files, per-file fsync and destination rereads;
source hashes are checked again before atomic directory publication. Failed
partial copies and existing destinations are preserved; nothing deletes source
records. It does not automatically retry a failed copy over an existing final
directory. A CLI alarm complements cooperative copy deadlines; the magistrate
must supervise the process for kernel I/O hangs as well.

Post-window compares identity/counters and runs an enclosing whole-second
`log show --style ndjson --info --debug` query. Any matching Disk Arbitration or
kernel storage row is conservatively an event; malformed/unavailable evidence
is an event too. It returns counter differences, event rows and the raw-log
digest, persists a lead hold, and prevents remount/re-arm while a prior arm
receipt awaits post-window. It does not read study outcomes or assign losses to
the campaign ledger; that consequence remains the magistrate's integration.
