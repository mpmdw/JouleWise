enumeration but omitted native `stat`, `lstat`, `access` and `readlink`.
The real arm collector in early probes consequently made existence checks
against the model locators named in the original configs under `/Users/edr`.

directory.” This violated the user's no-metadata-access rule. No model or
session contents were opened through those locators: opens were already
blocked. It is not claimed that those early probes were fully isolated.

The guard now intercepts all four metadata operations before native access,
and the new guard regression exercises the denials. Later input variants use
tiny local synthetic model files and fresh hashes; no prohibited locator is
resolved or probed to construct them. Absolute data locators remain text.
The early roots are development evidence only, not accepted fixture inputs.

The early integrated meter processes also reached the real libusb lookup.
Their own headers record four failed attempts, each reporting no matching
USB device. This was another violation of the synthetic-source boundary;
no attached meter was opened or measured according to those records. The
new source substitutes the library object below the unchanged `UsbDevice`,

native libusb library load is attempted. Early lookup-bearing roots are
excluded from fixture evidence.
