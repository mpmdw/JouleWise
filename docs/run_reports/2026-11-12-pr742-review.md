5. **LOW. The stand-in meter's offset is read with two separate clock calls.**
   `joulewise/align/w1_prequal.py:1551-1552`.

A later poll recovers, so the worst case is a slower ready, not a wrong verdict. On Linux, RAW and MONOTONIC also drift apart under NTP slew (parts per million; negligible over these seconds-long windows).
   Fix: none required. If it ever flakes, subtract 1 ms from `OFFSET`.
