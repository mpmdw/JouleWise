## Findings

**F1 (fix, PR body): gate ledger row 3 says "CI green ... RUN 2bff480aa", but CI on the head has not
run.** At 16:08 PST run 43334329539 (`ci`) was still queued and `gate-ledger` was skipped. The only
green Linux evidence is the temporary `zz-probe` run on 7f09f388d, which runs this one module, not
the suite. Row 3 should read NOT-RUN/pending until the `ci` run on 2bff480aa finishes. Row 2 (whole
suite on the merged tree) has no tail recorded either.

**F2 (fix, PR body): "passes on macOS" is true only because macOS takes the `/bin/sleep` path.** The
interpreter stand-in does not work under a macOS framework Python: the `bin/python3.13` stub re-execs
`Python.app/Contents/MacOS/Python` and the kernel then reports argv[0] as that path, not the marker.
The stand-in docstring's "this interpreter, which ignores argv[0]" should say this holds for
non-framework builds (Linux). No code change needed.

**F3 (optional, pre-existing): the first half of the target test does not test executable
identity.** The window process is a child of the test process, so `arm.agent_census` ignores it as
`own_tree` whatever `identify` returns; the test passes with `identify` forced to `agent`. Asserting
`census["ignored"][0]["reason"]` would state which rule fired. Unchanged by this PR.

**F4 (optional, latent): `_live` raises `SkipTest` when the child's argv never equals the requested
argv.** If the interpreter stand-in is ever selected on a host whose Python rewrites argv[0], most of
the class would skip rather than fail. Not reachable on ubuntu-latest (target test ran `ok`, not
skipped) or macOS. A CI-side check that this module skips at most the Darwin-only test would close
it.

**F5 (optional, pre-existing): the second half cannot tell "identified as agent" from "process
already dead".** A dead `claude` stand-in leaves an undecided line, which is also kept, so
`assertFalse(census["clean"])` and the stdout equality hold either way. Asserting the kept reason is
`agent_executable`, or that the pid is still alive after the census, would make it discriminate.

**Nit:** the comment in `marker()` ("the kernel executable is sleep") and the `window_process`
docstring are stale when the interpreter stand-in is used.
