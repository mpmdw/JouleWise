## Class rules built (EVIDENCE-INVARIANTS)

- **battery**:
  - `battery-count`, `poll-edge`, `poll-error`: `2 + (CPU samples + load errors) // int(battery_poll_s)`.
  - `battery-work-open`, `battery-work-close`, `sensor-bracket`: the opening and closing samples on the work's wall bracket, with Step D's inventory sweeps mapped through the paired stamps.
  - `battery-census`, `tick-window`: one CPU origin and one epoch offset over the hull of the pairs. Each census is at or before its battery sample. The periodic sample of tick k lies after the read of the (k−E)-th success and before the (k+1)-th, with the closing census after the last tick.
  - `drain`: equality is `battery_evidence`; presence stays `receipt_contract`.
  - `bound-battery`, `battery-raw`, `battery-terminal`, `battery-order`: now on both paths. Functions: `_check_callbacks`, `_check_battery`.
- **census**:
  - `pid-present`: the excluded runtime PID once in each snapshot.
  - The other census classes are now on both paths for D and X.
- **status**:
  - `observe-status`: idle and recovery status is `{}`.
  - `status-wire`: four keys, or one nonempty `error`.
  - `status-after`, `pm-before`, `pm-cache`, `cached-state`: one reachable cache history (`_check_gated_status`).
- **sensor**:
  - `smc-wire`, `smc-errors`: the issued reader's shapes, with the success bytes decoding to the value (`_smc_entry_ok`).
  - `journal-seq`: wall order is judged on a correctly numbered journal only, so the sequence names the fault.
- **Step**:
  - `inventory-raw`, `inventory-wire`: each sweep re-derived with `thermal.sample` from the reader's inputs, the enumeration complete, `phase: null` (`_check_inventory_sweep`).
  - `inventory-start`: the first sweep is before the main session opens.
  - `step-wall`: the wall is the one the intercept I_D was taken from.
  - `release-copy`: the receipt's `g0_release` is the G0 interval's.
- **PM rows**, `raw-pair`: each interval, recovered from its raw elapsed time, lies inside the bracket.
- **member**:
  - `session-nesting`.
  - `turn-wire`: the witness count, before stamp order.
  - `clock-domain`, `seed-identity`, `turn-bracket`: an absent field is refused by its own class.
  - `period-config`, `token-count`, `admission-count`, `phase-total`: an absent field the frozen contract also requires is refused by the owning class (the table's `missing` reason). `drain` and `desk-owned-required` keep `receipt_contract`, as the table rules.
- **D_bank**:
  - `gate-order`: the episode's gate identity against its begin row, before shape.
  - `gate-stamp`: the whole paired stamp before the persisted row (`gate-rows` reorder included).
  - `early-deadline`: the deadline origin, checked before the frozen workload replay, which still decides last.
  - `runtime-cut`: the receipt flags are the joined episode's.
  - `duty`: the T_dead_s claim is `duty_budget`.
  - `desk-*`: now on both paths.
- **turn-parse**: a protocol stop the episode lacks is `workload_replay`.
- **launcher**: `outer-open`, `outer-close`, `outer-next`, on both paths when the row is held.
- **prior-close**, **CPU**, **replay inputs**, **soak**: now on both paths (launch order `after`, D and X load, battery, outer statistics).

`launch-config`: built by `_runtime_config` (R4), as RL-216 R2 rules; see the fix-pass section. A pre-dispatch refusal was built in the round, then reverted.

## NEEDS_SPEC (ruled by RL-216: R4 (a) to (d))

1. **One outer file without the other in an archive.** RL-215 rules the archive with both outer files (compare as native) and with neither (archived custody).
