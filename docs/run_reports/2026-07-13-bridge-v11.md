## What v1.1 changes (contract: `docs/contracts/bridge_protocol.md`)

1. **Discussion lane** (§1): read-only `GENRE: discussion` MCP turns need
   only 6 header fields; BASE_HEAD required when advice depends on repo
   state; context-capsule guidance; compact same-thread continuation deltas.
2. **Session wrappers** (§6–7): `scripts/bridge session-open`/`session-close`
   collapse the 6-command write ceremony into 2 — fail-closed open (failure
   after lease acquisition abandons with recorded reason), immutable receipt
   as the ONLY scope-check digest anchor, close outcome matrix (DONE
   releases; early-return/BLOCKED/FAILED retain; non-OK verdicts retain and
   exit nonzero), digest-aware idempotent re-close, write-sessions-only in
   v1.1 (DISCUSSION close refused). `session.lock` serializes every
   bridge-state mutation (wrapper-spawned primitives delegate via
   `BRIDGE_SESSION_LOCK_HELD`; order session.lock → bridge.lock).
3. **Tolerant envelope** (§2): minification and the closed key set dropped;
   sentinel + one final-line JSON object with five normatively-typed
   required fields stays mandatory; trivial discussion turns may skip the
   four-heading body.
4. **Reverse consult** (§8): per-call `effort` (`high`|`xhigh`), validated
   `CLAUDE_BRIDGE_EFFORT` default, `[consult effort: …]` echo line, injected
   example envelope; protocol-deviation path now strips the child trailer and
   emits exactly ONE synthesized FAILED envelope (v1 emitted two sentinels —
   a v1 bug caught in this session's design consult).
5. **Peer channels + proposal diffs** (new §): per-objective discussion
   threads, never counted as independent review; proposal diffs are bounded
   advice (aggregate ≈3 files/200 lines per objective; category carve-outs
   route to leased writes) with a durable provenance record duty on the lead.
6. **One-home dedup**: effort-tier prose lives only in
   `.claude/skills/codex/SKILL.md`; agent/command/CLAUDE.md compress to the
   ratified one-line pointer. Enforcement-boundary guardrails intentionally
   stay explicit at their surfaces.
