## Result and authority

Implemented both explicit lead rulings in the engine-r23k brief.

1. `summary.seed` (the raw adapter's recorded `Episode.seed`) must be an
   integer equal to the roster's `seed_index`. Production writes this index,
   not its derived uint64 sampler seed.
2. Independently, parse the member's bundle config and episode spec and call
   production `sampling.seed_inputs(config, spec.enable_thinking)` and
   `sampling.episode_seed(..., 'shade/'+slot.task_pair, slot.seed_index)`.
   Require equality with `expected_episode_seed`. Either failure retains the
   `seed_identity_differs` exclusion class and prints its distinct
   `seed_index_differs` and/or `derived_seed_differs` reasons.
3. Captured raw and desk exports require a relative, digest-bound
   `config: {path, sha256}` reference. Both loaders verify it, retain parsed
   config data/provenance, and include the reference in `input_census`.
   Missing/inline config references and changed bytes under an old digest
   refuse. An uncaptured member needs no config. Config paths, task factories,
   cache references and model paths are treated as text only.
4. C/T non-anchor and supplemental-sentinel IDs use production
   `align-v4-<window>-e<ordinal:02>`. W1-kit anchor IDs, release window prefixes
   and exact slot-by-slot checks remain intact. Old `episodes-a/b` names
   refuse in both observed rosters and declared manifests.
