## Findings

1. **Wrong-window plan/kit pair can satisfy custody (P2).**
   `joulewise/align/v4_analysis/io.py:124`–143 binds plan member IDs, ordinals
   and hashes, but never checks the plan's `window_id`, `plan_id`, schema or
   `series_manifest_sha256`. Production `align_v4_series.build_files` deliberately
   reuses W1 anchor config bytes and local IDs across C/T windows. In a synthetic
   C1 partial capture containing only its four anchors, attaching C2's plan and
   C2's matching anchor kits passes `load`; `analyze` marks all four anchors
   eligible. The plan explicitly identifies C2. A foreign plan with a captured
   D member is correctly refused because D run IDs are window-specific.
   Thus this is a partial-capture wrong-artifact admission, not evidence that C2
   held-out members contaminate C1. Bind C/T plan identity to the selected window
   and frozen series; validate W1 using its distinct producer schema/plan ID.

2. **Malformed BenchmarkConfig aborts the release input (P2).**
   `io.py:143` calls `bundle_config_bytes`, whose `BenchmarkConfig.from_mapping`
   at line 106 can raise before `_config_identity_reasons` runs. With one member's
   kit and bundle carrying an invalid `schema_version` and all supplied byte
   digests updated, `load` raises `SchemaError`; the CLI would refuse the entire
   input. Direct engine screening would assign `config_invalid`. Invalid episode
   JSON inside `prompt_text` and a sampler-less spec do survive loading and
   exclude only that member, as required.
   Lead ruling needed: preserve the supplied member-only invalid-config rule or
   explicitly narrow it to valid BenchmarkConfig envelopes. Recommend the former,
   retaining digest failures as custody refusals and excluding invalid members
   before any fit. An invalid kit cannot produce normalized bytes through the
   normal writer; this witness tests malformed-export recovery, not a claim that
   a native writer produced such a bundle.

The two unmet requirements are executable `expectedFailure` tests in
`tests/align/test_v4_r23l_sol_review.py`; they must not be counted as green
qualification. No production fix or policy reinterpretation was made here.
