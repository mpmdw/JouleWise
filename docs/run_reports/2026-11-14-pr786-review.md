## Findings
1. (Info / Low) A past deadline with observable "none" yields the alarm `DEADLINE_PASSED_UNCHECKED:none` on every armed-and-idle CURRENT once the deadline passes. That is arguably the intended "armed span overran its deadline" signal, but it is worded as an unchecked observable. Pre-existing, so not a blocker. Optional follow-up: either special-case "none" or document the alarm.
2. (Info) The tests cover none/null (accepted), none/"bad" (refused), and the existing real/missing deadline (refused). Not covered: bool deadline, and real/explicit-null deadline. Both behave correctly in my scratch run; adding them is optional.
3. (Info) The condition `wait and (deadline is not None or observable != "none") and not number(deadline)` is correct but dense. It is equivalent to: for a non-empty wait, the deadline must be numeric unless it is None and observable is "none". No change needed.

No blocking findings.
