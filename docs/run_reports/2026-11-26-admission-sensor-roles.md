# Admit the pinned cadence writers' operational records

The lead assigned this [AGENT] repair after the RL-217 E.5 stage-1 rehearsal refused the first soak reference at `sensor_roles.fan_keys`. Mission M0 found no active stop card. The branch starts at `7c799f2f1` on `align/2026-11-14-look-manifest`. The sweep used Git source at the three writer pins. Verification used synthetic inputs, source and registration metadata.

The sweep found **23 mismatches**. Each Fixed row counts once, including grouped fields serialized together. The soak policy is the same closed object the thermal journal carries. Both now enforce distinct fast and slow keys, distinct fan and record lists, and the writer's sensor-key and digest syntax. An empty fan list is valid. `record_keys` can be absent, empty or overlap the role keys. The idle runtime always supplies a validated policy, and the soak serializer itself explicitly emits null when its result has no policy. The test exercises both serializer paths at each pin.
