## Cross-model comparison (same workload, same harness, same machine)

| | Qwen2.5-1.5B-4bit | Qwen3.5-122B-A10B-4bit | ratio |
|---|---|---|---|
| Active params | 1.5B | 10B | 6.7× |
| Gross energy / 512 tok | ~47 J | ~304 J | 6.5× |
| Energy per output token | ~87 mJ | ~583 mJ | **6.7×** |
| Decode throughput | 257 tok/s | 46 tok/s | 0.18× |
| TTFT | ~94 ms | ~270 ms | 2.9× |
| Implied decode power | ~23.5 W | ~27.5 W | 1.17× |

**Finding (first real Q4 data point):** energy per output token scaled
almost exactly linearly with ACTIVE parameter count (6.7× params →
6.7× mJ/token), while total parameters grew 81×. Decode POWER barely
moved (~23.5 → ~27.5 W — the SoC runs near its power envelope either
way); the energy difference is almost purely decode TIME. This is
textbook memory-bound MoE behavior and exactly the kind of
fixed-vs-marginal structure Q4's model fits — two points on the curve
now exist.
