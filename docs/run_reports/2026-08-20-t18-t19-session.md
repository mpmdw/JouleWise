**Terms used below, each glossed once here because they recur.**
- **Full-canonical gate** — the entire test suite (`~3,800` tests, ~47 min)
  run at the exact head being merged, green, before the merge button. Not CI;
  a local run whose log is kept.
- **Gauntlet** — the standing shape for delegated work: implement under an
  exhaustive declared write scope → an independent *refuter* attacks it →
  fix round → *delta re-audit* of the fix round (fix rounds introduce
  defects, so the fix itself is re-attacked).
- **Refuter / lens** — a fresh reviewer whose job is to break the work, not
  to approve it. A *contract lens* asks whether the code does what the ruling
  said; an *execution lens* builds and runs attacks against it. Two lenses on
  one blocker must be distinct in that sense.
- **Remand** — the magistrate sends work back not because it is wrong but
  because it touched something it was not allowed to touch.
- **Frozen surface** — one of the four estimator source files whose bytes are
  hashed into the live D-079 calibration acceptance. Any byte change there
  invalidates the acceptance, so those files are off-limits outside a family
  boundary.
- **Same-signature** — two consecutive fix rounds failing for the same
  underlying reason, which under rule 11 forbids a third round and requires a
  consult instead.
- **Cold ratification** — a fresh instance with no session context rules on a
  mechanically assembled packet before a ruling becomes final.

### 1.2 #162 — FREEZE-REPLAY-EXPIRY-01

Sitting finding **B-12** (packet row, seat L6 / WO-L6-B; severity re-graded
nit → blocker by sitting ruling ⊙C-12). The defect: `FREEZE_AND_ARM` rows
could report PASS from *expired* evidence, because the generic evidence
authenticator only compared `valid_until_monotonic_ns` when a caller
volunteered a timestamp. The fix makes `_authenticate_generic_evidence_item`

freeze-replay call site left the new tests green 4/4, because the generic
fallback calls the same globally-mocked `time.monotonic_ns()`. The cure was
to *simplify*: drop the redundant explicit per-site forwards and rely on the
single fail-closed mechanism, so there is one thing to test and it is tested.

## 2. The N-5 canonical flake, root-caused (`46d710f`)

N-5 entered the record in T17 as a *verification gap*: the D-144 seat pass
saw `test_logical_producer_delay_preserves_exact_evidence_bytes` fail with a
7.4 MB diff, could not reproduce it, and the pass reclassified it rather than
ruling it. It reproduced here, in the `canonical-pr163b` run at a PR head —
which is what made it fixable.

**Cause.** The test derived its writer origin from `time.time()`. Every
governed byte it then compared was therefore a function of *when unittest
discovery happened to reach the test* — so the comparison passed or failed
depending on suite ordering, and the failure was a whole-artifact byte diff
rather than a named field.

**What was ruled out, executably.** The standing N-5 hypothesis was a cache
(`_SELF_CONSISTENT_CALIBRATIONS`). Refuted: the witness never touches it, and
full reducer-suite pre-runs pass.

**Fix.** Pin the origin, which is what the test's actual contract —
suspension-immunity — requires; and replace the monolithic comparison with
per-artifact `subTest`s carrying digests, so the next failure names the
artifact instead of printing 7.4 MB. Both 506-test scoped orders green.

Cause classified **probable**, not certain: the historical event streams from
the original seat-pass failure were not retained, so the reproduction here
and the original cannot be byte-matched. That is recorded as a limit of the
diagnosis, not smoothed over.

## 3. The B7 paper claim-integrity ruling (`b7adb14`)

**What B7 was.** The two-week sweep's only claim-bearing finding: the paper
quoted two floor magnitudes — `8.611855 J` (worst-case composition) and
`1.869502 J` (the two-shared-edge estimator) — without provenance.

**What the investigation found instead.** The finding as filed was already
cured (the relationship between the two numbers *is* stated correctly at
`draft-v1.md:272`), and the cited line list was wrong: five of the six named
lines sit inside an HTML comment block (`:357`–`:409`), a byte-fenced
`REPLACE EXACT` / `WITH` swap script, not published prose. The real defect
was **provenance and era**: both numbers trace to a single lineage — the a5
decode ABBA corpus, anchor-v2 pipeline, computed against the *original n=19*
calibration-acceptance generation — and every mention of them in their own
primary source is prefixed `NON-CLAIM`.

**The sharpest new finding.** The commented swap block hard-codes
`1.869502 J` — an a5 / anchor-v2 / n=19 number — into sentences that would
read "*Comparative results issued in this cycle … the resulting comparative
false-effect floor is 1.869502 J*." When that block fires at the first
post-freeze mint, the mint produces a *new* floor from prospective evidence;
the a5 number is not it. The queue row's own "do not apply a partial swap"
instruction pressures the operator toward mechanical application. That is an
armed landmine, not a stale citation.

**The ruling: the stricter reading.** The investigation offered two readings
and said no located ruling decides between them: (i) admissible with full
labels, or (ii) these numbers leave the live draft entirely. The magistrate
took (ii). Both literals were removed from six live paper sites and four
armed swap sites, from the swap-block anchors, and from `TASK_QUEUE.md:247`;
the six live sites go qualitative with the era disclosure extended, keeping
the one surviving fact (which estimator is tighter). The armed swap block was
disarmed into registry bracket tokens:
`[F_decode_contrast_cmp_two_edge_J]` as MEASURED / KEY_FROZEN /
VALUE_UNISSUED, and `[F_decode_contrast_cmp_worst_case_J]` deliberately
STOP_FILL / SUPPLIER_UNKNOWN — because the mint issues one comparative floor
per cell under that cell's selected estimator, so no output field supplies a
same-cell worst-case counterpart. Registering it MEASURED would have re-armed
the exact defect just removed.

**Two deviations from the brief, recorded rather than absorbed.**
- **D1** — the brief predicted that removing the a5 numbers would make
  `:230`'s blanket no-superseded-energy-values clause true. It does not:
  §3/§7 still carry a9/a10 superseded-era energies, which D-148 cl.7 requires
  *disclosed*, not deleted. The clause was repaired honestly instead
  ("…except the explicitly labelled instrument diagnostics of Sections 3
  and 7").
- **D2** — the STOP_FILL choice above.

**Blast radius beyond the paper.** The same false-issuance wording was struck
from `CLAIMS_STATUS.md` and from the 70h-plan's definition of DEFENSIBLE,
