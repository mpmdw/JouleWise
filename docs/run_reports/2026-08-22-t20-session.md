**Terms used below, each built once here because they recur.**

- **Work-order kernel** — `docs/process/state_kernel.json`, the machine-readable
  list of live work orders. A *kernel transaction* is the rule that a kernel
  edit, the docs regenerated from it, and its pins land in one commit or not at
  all.
- **Gauntlet** — the standing shape for delegated work: do the work under an
  exhaustively declared write scope → an independent **refuter** attacks it →
  fix round → **delta re-audit**, which re-attacks the fix itself, because fix
  rounds introduce their own defects.
- **Refuter, and its lens** — a fresh reviewer whose job is to break the work,
  not to approve it. A *contract lens* asks whether the artifact does what the
  ruling said; an *execution lens* builds and runs attacks against it. A verdict
  of **SURVIVES** means the attack failed; **REFUTED** means it succeeded.
- **Cold gate** — a fresh instance with no session context rules on a packet
  that was assembled mechanically (by rule, not by summary), paired with a
  second reviewer of a different model for cross-model diversity. Used when the
  magistrate's own judgment is the thing under question.
- **Crossover** — in a two-seat debate, a seat abandoning its own position after
  reading the other's. A *double crossover* is both seats doing it at once,
  which means the resulting agreement is an artifact of the exchange rather than
  independent confirmation, and must not be counted as two votes.
- **Escalation trigger** — two consecutive rounds failing with the same
  signature (same defect class, same wedge, same missed call site) is evidence
  of a structural problem, so the next spend is a consult or a different
  instrument, never a third round of the same shape.
- **`_v4`** — the next measurement family. Publishing it requires a *freeze*
  (the code and evidence are pinned to exact bytes) and a *mint* (the numbers
  are issued). The mint license is Ed's authorization for that to happen at all.
- **Changed-set contract / allowlist** — the `_v4` freeze refuses to arm if the
  repository changed in any way not on an explicit list of exact file paths.
  That list currently stands at **112 paths**; its size is a ruled number, so
  growing it is a contract amendment, not an edit.
- **Pinset** — the file that records which evidence packs and ordinals the
  family is pinned to. It has to be written *during* the transaction, which is
  what makes its own path a changed-set problem: see §4.
- **STOP_FILL** — a registry cell deliberately marked as having no supplier, so
  the paper's rendering machinery refuses rather than inventing a value.

Three real catches, all code-grounded, none of them the magistrate's.

**The ruling (D-151), adopted: O-1-D, the versioned-successor pinset.** A closed
code-enumerated chain with a pre-derivation reviewed delta and an unchanged

**The standing rule minted here, binding on all future transactions:** *no
