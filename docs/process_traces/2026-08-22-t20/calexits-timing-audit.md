## 3. E-4 constraint — forced maintenance must still start

`test_forced_auto_maintenance_mutation_reproduces_cleanup_race` deliberately proves two things: local maintenance controls suppress detached maintenance in the control, and removing exactly those controls causes detached maintenance to start (`:1737-1766`, asserted at `:1777-1786`). Therefore disabling Git maintenance—the technique appropriate to unrelated fixture repos—is **unavailable for this test**. That is settled by E-4 and its `UPHELD-WITH-FOLLOWUP` review.

The permissible follow-up is assertion-shape hardening:

1. Keep the exact detached-maintenance-start assertion.
2. Keep `ENOTEMPTY` and Python-3.11 `ENOENT` as the only accepted raw cleanup-race errnos; do not narrow or widen E-4's upheld allowlist here.
3. Make the real-Git leg assert a complete causal Trace2 topology in one event domain, including the detached parent terminal before trace-tempdir release. Treat observed overlap versus pre-write completion as explicit branches rather than depending on ambient host scheduling.
4. Add the E-4-recommended deterministic injected writer/remover harness for both interleavings. The existing quiescence test remains the discriminator that cleanup-before-writer-join is rejected.

This improves determinism without suppressing the behavior the test exists to witness and without re-litigating E-4's verdict.
