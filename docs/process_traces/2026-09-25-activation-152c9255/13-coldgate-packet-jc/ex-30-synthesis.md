## Terms (built before use)

- **Envelope.** One quiet measurement window: census-clean machine, one model loaded, a fixed schedule of runs while `powermetrics` records CPU+GPU+ANE power. One finalized manifest = one window = one envelope (CGW:63). Energy of a run = gross joules summed over the rails between the run's start and end edges (AP:49).
- **ABBA block.** Four consecutive runs in the order A, B, B, A. The block difference is δ = (B1 + B2 − A1 − A2)/2 (code: `joulewise/detection_floor.py:1449-1453`). The symmetric order cancels any linear drift over the block.
- **ABBA null block.** An ABBA block in which A and B are the *same* configuration (same model file, prompt bytes, budget, problems, seed). Nothing differs, so δ measures only instrument error and machine-state change. If every δ were 0 the instrument would be perfect.
- **n_cal.** Number of null blocks per calibration envelope. Ruled equal to the claim envelopes' fixed count n_reg = 10 (CGW:69, "artifact n_cal == n_reg").
- **k_cal.** Number of calibration envelopes retained (each must hold all n_cal blocks). Minimum 5 (CG:3).
- **F_est (the noise floor).** Take the k_cal envelope means of δ; call their mean `mean_cal` and their sample SD `s_cal`. Then F_est = g(k_cal)·(|mean_cal| + t_{0.975,k_cal−1}·s_cal/√k_cal) (CG:3). g is a small-sample penalty, g(k) = max(1, √(9/(k−1))), so g(5) = 1.5, g(≥10) = 1 (`detection_floor.py:846-855`, reference n 10 at `:121`). t_{0.975,4} = 2.776. A claimed difference θ̂ must satisfy |θ̂| > F_est strictly, besides Holm and an interval test (CG:3 conditions 1–3).
- **J/correct.** For model m, level L, thinking budget b: `e` = mean gross J per attempt, measured by re-running a random subsample of problems inside quiet envelopes; `p` = fraction correct over all n ≥ 128 frozen problems, measured in separate *accuracy runs outside quiet windows*. C = e/p (AP:57, AP:10 items (4)–(6)). Note: p never comes from a quiet block.
- **Log contrast Δ_L.** R_L(b) = C_8B,L,b / C_1.7B,L,b (which model is cheaper per correct answer at budget b). Δ_L = log R_L(b_high) − log R_L(b_low): did lengthening the thinking budget change the models' *relative* efficiency (AP:65). Since log C = log e − log p, Δ_L = Σ_c a_c(log e_c − log p_c) over four cells c = (8B,hi),(8B,lo),(1.7B,hi),(1.7B,lo) with signs a_c = (+,−,−,+).
- **Seeded decoding / byte-match.** Every MATH run samples with one pinned random seed and pinned sampler settings, so a repeat on the same software stack must reproduce the same token IDs and output bytes (AP:37). Each quiet energy rerun must byte-match its accuracy-run trace; mismatches count against a registered ceiling, and exceeding it withholds the cell (AP:47; ceiling value OPEN there).
- **Dimensionless margin.** CG-4(f) lets AP-5M v5 register, instead of an additive J/correct difference, "a registered dimensionless margin with a derived, matched floor" (CG:9). Here: a floor in natural-log units, applied directly to Δ_L. One log unit of 0.01 ≈ a 1 % change in the ratio.

**Worked example of the majority floor rule** (Sol, Opus, Fable: CG-1's formula applied to null blocks run through the same log arithmetic as Δ_L). *Assumed* numbers throughout.
1. One null block on the 8B (all four runs identical config): A1 = 400.0 J, B1 = 401.2 J, B2 = 399.6 J, A2 = 400.4 J. Log-block difference δ = (ln 401.2 + ln 399.6 − ln 400.0 − ln 400.4)/2 = 0.00050.
2. Envelope value x_8B(i) = mean of its 10 δ's. Do the same for the 1.7B in its own envelope i.
3. Five envelopes per model (Opus's example, `17-jc-opus.md:54-57`): x_8B = (+.004, −.003, +.006, +.001, −.002), x_1.7B = (+.002, +.005, −.004, +.003, .000). Pair them in start-time order: ν = x_8B − x_1.7B = (.002, −.008, .010, −.002, −.002). This mirrors Δ_L, which is (8B budget contrast) − (1.7B budget contrast).
4. mean ν = 0.0000; s_ν = 0.00663; F = 1.5·(0 + 2.776·0.00663/√5) = **0.0124** log units (recomputed in calc.py: 0.01235).
5. No correct count appears anywhere: in a null the same cell sits in A and B, so log p_A − log p_B = 0.

## J2 — Seeds and correctness noise

**What the draft says (verified).** One pinned seed for every MATH arm and repeats must reproduce token IDs and bytes (AP:37); if even separately generated traces cannot reproduce, headline energy is blocked (AP:39); quiet reruns use "the same prompt, seed, runtime and settings" and must byte-match the accuracy-run trace, against a registered ceiling (AP:47); the scorer is pinned and takes the last parseable answer inside the allowance (AP:23); p is correctness over all n frozen accuracy problems (AP:57). **Implication for "null":** the null of this study is "same cell, same seed, same bytes", and p cancels in the null *by the estimator's definition*, not only by determinism: both slots of a null block are the same cell, which has one p from the accuracy run. Fable's reason ("p is fixed by the bytes", `:9`) is sufficient but not necessary; Opus `:23` and Astra `:128` state the stronger reason. Byte-identity matters for **e** (A and B do the same token work) and for coherence of e with p (same traces).

**(i) Agreed (unanimous).** Same model + same seed is the correct null; zero correctness variance inside it is correct, not an understatement (Sol `:126`; Astra `:142`; Opus `:80`; Fable `:33`). Seed-varying nulls calibrate a different experiment and err large (Opus sim median floor 0.59, `:69`; Fable ≈3.6×, `:7`). Problem-sampling uncertainty belongs to the claim interval (see S3). Claims are worded "at the registered seed / frozen problem set"; a seed-averaged claim needs a new design with seeds in *both* science and null (Sol `:130`; Astra `:156`; Opus `:89`; Fable `:33`). Unverified premise all four flag: seeded MLX sampling reproducibility on Metal. Additional verified fact (Fable `:33`): the runtime at HEAD samples greedy at temperature 0 (`joulewise/adapters/mlx_runtime.py:984-988`; Fable cites it without `adapters/`) — the pinned-seed sampler (lane A283) is not landed.

**(ii) Splits.**
- **S4 — what happens if same-seed replays are not byte-identical.** Fable: a random-count floor ("(a) as framed") becomes necessary, or fix the stack; refuse non-identical blocks and print the rate (`:15,:49`). ## §P — Magistrate proposals (argument for the cold judge, not authority)

- **P-0 (BLOCKER, independent of the floor choice): the claim-side accuracy term (S3).**
  - The ruled CG-1 estimates the standard error only from envelope-to-envelope scatter. For any contrast whose estimand contains a correctness fraction p̂ shared by all k envelopes (J/correct, and its log form Δ_L), the sampling error of p̂ enters as V/k when it should enter undivided, or not at all. At true Δ_L = 0 the gate then admits false directions: ≈0.39–0.81 per level on the seats' and the subagent's desk checks.
  - **Proposal:** a cold-gate AMENDMENT of CG-1, explicitly labelled. For estimands with a shared accuracy term, SE² = V_env/k + V_acc, where V_acc is carried once. V_acc comes from a ruled paired bootstrap over the frozen problems: models and budgets are paired on the same problems, and bootstrap replicates resample problem ids jointly across the four cells. The draft's own bootstrap (AP:61), now ruled rather than OPEN, supplies it. Degrees of freedom follow the smaller of k−1 and the bootstrap's effective n.
  - The CG-4(e) desk simulation is re-run on the full five-level gate at the planned n_acc and k before any freeze. False-admission per family must be ≤ α with its finite bound.
  - Until this amendment lands, no v2 registration with a shared-accuracy estimand may freeze. WR-3's validator refuses with `claim_shared_accuracy_term_unruled`.
- **P-J1: option (c), unanimous.**
  - Unit `ln_ratio`, added to the F_est unit enum (a WR-1/WR-9 amendment, since `{J}` is the enum at the CG-4 PR).
  - Floor rule: CG-1's F_est formula applied to a null composed exactly like Δ_L.
  - **S1: the directly matched null (Sol, Opus and Fable's preferred form), not Astra's worst-case sum.** Astra's sum errs large, by about 2× root-sum-square and inflated further by per-cell g·(|mean|+t·s/√k), and would hide real effects of the size the headline expects (0.2–0.3).
