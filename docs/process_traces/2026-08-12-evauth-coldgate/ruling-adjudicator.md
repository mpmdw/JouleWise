## PART A — Disposal of Q1–Q3

**Q1 — Ruling: (a), adopted with two corrections to the delta's prescription. The injection class is structural in Python; the prescribed remedy is the terminating design only when paired with an explicit boundary declaration and an executable public-surface lock.**

The class is structural: any module attribute is substitutable in-process, and this codebase's own tests prove patchability of private names is endemic and sanctioned (`readiness._current_boot_session_id`, `evidence._execute_unittest_suite_subprocess`, `os.replace`, `readiness._discover_evidence` are all patched by the shipped tests). A renamed `_DERIVERS` remains patchable; a `MappingProxyType` can itself be rebound by module attribute assignment. Therefore no in-process design "closes" this class, and demanding one would be chasing an unattainable property. What terminates the defect is fixing what B1 actually is: a **public API affordance** for outcome injection, and a test suite that **normalizes** mutating the public surface — the same disease as the original `_suite_runner` kwarg, resurfaced one name over.

**Threat-model boundary adopted:** the adversary class is accidental/operational misuse, agent drift, and pattern-normalization — not a hostile in-process attacker. Justification, from executed evidence, not convenience: an in-process adversary needs no `DERIVERS` at all — it can patch any private name, or skip the author entirely and write receipt bytes to disk (consumers validate schema + predicate + bindings, not truth; only the author's authenticate mode fully re-derives). Since no code change inside the module can defend against that adversary, placing it inside the boundary would make every remedy insufficient and the round unterminating.

**The enforcement boundary IS:** (1) the sanctioned authoring path's public surface — CLI argv (`--pack-root` only), the one-parameter author signature, and the module's public namespace — must admit **no** name whose supply, mutation, or rebinding alters authored outcomes or dispatch; (2) tests may patch only underscore-private seams, so no public-mutation pattern is ever normalized; (3) everything beyond that line is defended by the consumer validation stack, authenticate-mode full re-derivation, and process controls (audit trail, D-050 hashes, review gates) — not by code.

**Corrections to the delta's prescription:** (i) `MappingProxyType` is neither necessary nor sufficient — permitted as belt, but the gate is the executable namespace lock (conditions 1–2 below), because the proxy can be rebound and the underlying dict must remain reachable for the private test seam anyway. (ii) The remedy is incomplete without converting the three tests that patch the public mapping and landing a permanent forgery regression; a privatized dict with tests still teaching `patch.dict(evidence.DERIVERS)` would reproduce B1's normalization arm verbatim.

**Option (b) is rejected as excessive:** subprocess-only authoring buys nothing against the residual adversary (who writes forged bytes directly), costs the in-process ACID test that is currently the strongest end-to-end regression (author CLI → real freeze → 13 PASS + 1 N/A), and enlarges a fix round the night of the freeze — fix rounds introduce defects, proven twice in this program's own record.
