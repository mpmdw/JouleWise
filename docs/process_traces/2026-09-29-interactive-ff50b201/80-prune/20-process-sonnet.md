## Vocabulary used in this file (each term is defined here before first use)

- **Seat**: one delegated model session (a Sol/Astra/Opus/Fable run given one job).
- **Lens / refuter**: a seat that reads finished work and hunts for defects (a lens looks from one angle; a refuter tries to break a specific finding or ruling).
- **Cold gate**: a fresh Fable session, with none of the working session's context, that rules on a mechanically assembled packet; usually paired with an Opus refuter.
- **Fix round / delta re-audit**: a fix round is one batch of repairs after review; a delta re-audit is a fresh review of only that batch.
- **Same signature**: two consecutive rounds failing with the same class of defect. The written rule: the next spend is a consult, not another round.
- **Row N**: row N of the 12-row PR gate ledger in `.github/pull_request_template.md` (D-118/D-121). Light tier = rows 1, 9, 11, 12 only.
- **Claim path**: code or records that decide what number the paper may print.
