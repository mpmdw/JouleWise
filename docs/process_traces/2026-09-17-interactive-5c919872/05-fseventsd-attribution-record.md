## 1. Entry count of the event-log directory

```
sudo ls /System/Volumes/Data/.fseventsd | wc -l
  365498
```

`fseventsd` is the macOS file-system event logger. It writes its event logs as files inside `/System/Volumes/Data/.fseventsd`, one file per log chunk, and prunes old chunks itself. A healthy directory holds tens to a few hundred files. This one holds 365,498, and its directory link counter has been pinned at the HFS/APFS ceiling of 65,535 (`stat -f %l`, observed 19:22 and again in the 8789ee70 harvest record). Every new log chunk is created in, and every prune pass reads, a directory of 365 thousand entries; that is the CPU cost that reached 1,152 CPU-minutes between the 09-15 boot and 18:1x on 09-17.

## 4. Cure (Ed's keystrokes; irreversible, so not the magistrate's)

