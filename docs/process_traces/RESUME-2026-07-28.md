## 4. THE CRITICAL PATH: build the mint

`build_floor_cell` / `build_floor_artifact` / `build_absolute_record` /
`build_comparative_record` have **zero non-test call sites**.
`scripts/extract_detection_floors.py` writes the extraction report and stops.

**Blockers established by tracing and by a real attempt:**

1. **`claim_ready` requires an absolute AND a comparative record in the same cell.**
   a10 alone mints a structurally `smoke_only` artifact. **Mint #1 must pair a10's
   absolute cell with window C's decode comparative.** Verify first that they share
   backend, metric, window_class, condition family and stack identity — that is a
   go/no-go, not a task.
2. **The extraction report drops the uncertainty widths** at the extraction-to-canonical
   boundary, though the producer computes them. The comparative array is NOT
   reconstructible downstream. Fix: export them, and move `_WIDENED_FLOOR_KEYS` from
   the optional group into the required key sets so absence becomes a schema error.
   *This ~60-line change is the real closure of the defect class that consumed six
   abandoned fix rounds.*
3. **A 30-vs-37 member authentication mismatch.** The a10 phase spec selects 30
   members; the passed verdict authenticates 37 (30 phase + 7 reference). The
   30-member replay REFUSES. Extraction of the authenticated basis takes
   **20 min 36 s** on real data — budget for it.
4. **Windows C and D have no legal calibration scope name.** `_CALIBRATION_SCOPES`
   is `("window_a","window_b_revalidation","smoke")`. D-079 clause 4 adopts one
   general production name; proposed literal **`production_window`**.
5. `source_class` cannot simply be added — `_TOP_KEYS` is closed.
6. **Determinism hazard:** the extraction report embeds the absolute `runs_root`
   string; the mint must not copy it in, or `artifact_id` becomes machine-specific.

**In flight:** a contract commit on branch `impl/floor-mint` (worktree at
`scratchpad/floormint`) implementing blockers 2, 5, a metric vocabulary check and a
provenance validator. The mint script itself is not yet written.

**Design settled across three independent drafts:** `scripts/mint_floor_artifact.py`
takes two extraction reports plus a **declaration JSON** (the judgment surface —
backend, condition family, eligibility, scope) and emits one validated artifact.
No runner, no DAG, no CI mint, no batch mode. *Scripted is not automated:* run
frequency decides orchestration; cost-of-error decides check density inside a stage.

**Before mint #1:** pre-register expected values **from verdict-stage numbers, not
from a mint run** — a correlated expectation is theater. Mint twice, compare bytes.
Retain the adversarial probes (stripped widths, wrong class, degenerate scatter,
unit inversion) as mutations of the REAL artifact.

   Window B is not budgetable; `instrument_calibration_mismatch` stands.
3. **Pre-flight screen `pre.b_fiducial_s ≤ 0.033558756679900`.** Cause of window B's
   failure established: a **GPU DVFM power ramp** that the rectangular-pulse estimator
   aliases into an apparent onset shift (93.28% of the drift; the wall-clock term moved
   the *opposite* way). Detectable in the ~4-minute pre-calibration. Window B's
   pre-calibration exceeded the screen by 1.877 ms.
   **Retry semantics: cause-removal, not outcome-selection.** Re-running until the
   number passes is calibration shopping. A retry requires a named, removed cause,
   recorded as a deviation, both attempts preserved, bounded pre-registered count.
   Absent an identifiable cause, the window ends. Worked precedent: XProtect at 94%
   CPU, identified, waited out, relaunched clean.

## 7. Process rules encoded this session

Six rules and five clauses (cut from thirteen candidates by ruling — thirteen rules
from one session was itself the failure mode repeating).

- **operation-loop §0a R1–R3** (already encoded): never end a turn without a
  harness-registered wake source; a perishable resource outranks other work, with a
  stop-loss; any claim about the operating environment is a hypothesis until checked.
- **R4 — exit status is not evidence of work done.** A run is complete when its own
  artifact says so, never when the wrapper exits 0.
- **An absence-of-counterexample scan is not corroboration** until the scanned
  population is proven non-empty for the gated class.
- **Enumeration vs convergence:** a second audit round finding another missed call
  site of the same property means stop patching sites; the fix is a fail-closed
  default at one choke point.
- **Delta re-audit scoped to the DIFF, not the subsystem**, with a hard stop.
- **STANDING ESCALATION TRIGGER:** two consecutive rounds failing with the SAME
  SIGNATURE means the loop is structurally broken, and the next spend is a consult,
  not round three.
- Project-side (window_runbook + D-079): blind derivation; pre-registration states
  attribution fractions not binaries; retry semantics.
