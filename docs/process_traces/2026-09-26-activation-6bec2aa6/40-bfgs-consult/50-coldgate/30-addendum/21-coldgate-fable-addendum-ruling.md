## 4. Final texts v1.1 (supersedes Final texts v1 in full; the seat briefs quote these verbatim)

### A. Mechanism

1. **Phases.** `battery_float.PHASES` is the module constant `("arm_check", "publish_install", "t0", "validate_install", "t0_power_row", "slot_pre", "slot_post", "quiet_pre", "quiet_post", "bundle_pre", "bundle_post")`. This amends the enumeration in ex-01 §5.4; the schema id stays `joulewise.battery_float.v1` and the field set is unchanged. `observe()` is **not edited**; the enumeration is enforced by `authenticate_pair` (each reader requires its exact phase pair) and by a sweep test asserting that every production `observe(phase=…)` literal under `joulewise/` and `scripts/` is in `PHASES`. Identity: `quiet_*` binds `session_id` = the collector uuid, `slot`/`attempt_id` null, `plan_id` = the night plan id when the executor passes one; `bundle_*` binds `session_id` = `metadata.json.run_id`, `slot`/`attempt_id` null. `raw_path` = `raw/battery_float.<pre|post>.ioreg` relative to the container.

2. **Helper.** In `joulewise/battery_float.py`, after `authenticate_committed_verdict`: a frozen dataclass `PairVerdict(kind, status, reasons, pre_raw_sha256, post_raw_sha256, pre_update_age_s, post_update_age_s, delta_q_mah)` with `status ∈ {"pass", "battery_float_confounded", "battery_float_evidence_missing", "not_applicable", "unobserved_historical"}`; the core `authenticate_pair(record, custody_root, *, phases, identity, span=None) -> PairVerdict`; wrappers `authenticate_quiet_session(envelope_dir)`, `authenticate_bundle(bundle_path)`, `authenticate_capture(capture_dir)`. Per phase, in order: (a) phase absent, not a dict, `phase` ≠ expected, `session_id` ≠ `identity`, `raw_path` ≠ the fixed relative path, `raw_stdout_sha256` not 64-hex, `wall_time_s` not numeric → `evidence_missing`; (b) raw file unreadable or its digest ≠ `raw_stdout_sha256` → **raise `CustodyFailure`** (never a status; refuses the consumer's whole computation; never an exclusion); (c) `exit_code ≠ 0` or `timed_out` → `evidence_missing`; (d) `parse(raw, wall_time_s)` raises → `evidence_missing`; (e) predicate false → `confounded`; (f) when `span` is given, `pre.monotonic_after_ns` ≤ span start and `post.monotonic_before_ns` ≥ span end, else `evidence_missing: <phase> outside measured span`. Custody raises before any status; confounded > evidence_missing > pass. `delta_q_mah` is reported and never gates. A stored `passed` is never read. No committed verdict file exists for these kinds.

3. **Frozen functions.** `parse`, `_structure`, `_recorded_values`, `observe`, `require_pass`, `validate_window`, `predates_battery_float`, `authenticate_committed_verdict`, `load_committed_verdict`, `compare_verdict` do not change before S4; a test pins `sha256(inspect.getsource(fn))` of each. No exception is granted by this ruling. A golden test calls `observe` with each of the seven pre-existing phases through an injected runner and clock and asserts byte-identical records against a pre-S0 fixture.

4. **Guard.** This amends ex-04 §3.10: exactly one new allowlist row, `joulewise/battery_float.py::authenticate_pair → parse`; the six-row assertion becomes seven; a guard self-test asserts that a `parse` reference from any other new function in `battery_float.py` is flagged; the three wrappers call `authenticate_pair` only; a `PairVerdict(...)` **call** outside `battery_float.py` is a violation (`isinstance` references remain allowed).
