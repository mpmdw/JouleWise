# Harvest lane: the independent executing review (Opus 5.5, 2026-10-07)

## What this record is

This is one of the two gate records for the **harvest lane**. Both exist so that the program that will judge the
block-5 measurement windows can be pinned by name and digest before its first use.

The words this record needs:

- A **window** is one unattended measurement run on the measurement Mac. Block 5 has three.
- The **harvest** is the program that runs at the desk after a window has ended. It copies the window's files into
  an archive, checks them, and writes which measurements are kept and whether the window can carry claims. Its
  files are `joulewise/b5/harvest.py`, `joulewise/whole_window.py` and `scripts/harvest_b5_window.py`.
- **H_claim** is the last commit that changes anything a window reads; the **sealed inventory** lists the SHA-256
  of every code file at that commit. The windows run from a checkout of that code and never from the lane.
- The **harvest lane** is the branch `lane/2026-10-07-harvest-lane`. It carries ten changes to the harvest, one
  commit each, which the seal gate and two reviews required after the code the windows run had been fixed. The
  items are numbered K-4 to K-7 (from the seal gate's first stage) and H-8 to H-13 (from the review of the
  seal-landing lane and from cold pass 5); `15-harvest-lane-worklist.md` beside this file lists each with its
  source. The lane changes nothing a window executes: it reaches only the checkout the harvest runs from.
- A **reference** is one run of a small fixed workload placed at the start, the middle and the end of a window. The
  **drift screen** compares the references' energies to decide whether the instrument drifted during the window; a
  reference that cannot be used is **lost**, and the screen is then repeated on the references that survive.
- An **independent executing review** is a review by a seat (one model session working to a written brief) that
  wrote none of the code and that runs the code on inputs of its own, instead of only reading it.
