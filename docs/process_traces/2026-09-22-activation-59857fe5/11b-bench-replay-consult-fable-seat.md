Facts I executed: archived chain drift 0.160 / 7.6–10.1 s (12 rows); each envelope's plist is ~2 500 NUL-separated frames of ~52 KB, `elapsed_ns` ≈ 260 ms, `<date>` labels whole-second UTC; envelope-02's archived anchor endpoint is `1790069829.80176…80316` (bounded, ±0.7 ms); `power.argv` in every session begins `sudo -n /usr/bin/powermetrics`.

## Two findings the sketch does not account for

**F1 — a byte-identical replay under-measures the tail.** `derive_powermetrics_anchor_v3` boxes the first-record endpoint inside `[min(native)−2 s, max(native)+2 s]` and intersects that with the live `pre_spawn`/`first_parse` stamps (`uncertainty_evidence.py` ~1150–1230). Frames dated 2026-09-22T09:xxZ replayed on a later day give an empty set → `rate_aware_native_set_empty` → `align_frames` returns `[]` → `collect` skips `integrate_seconds` for every round and `reduce_interior` gets no frames. The collector exits 0, so `execute` measures a drift, but the finalisation tail it measures is the parse only; the per-round integration and the interior reduction — real production cost on the same inter-slot path — never run. Cure (§1).

**F2 — the covariate recorder is a `campaign.main` subprocess.** If the variable lives in the executor's `os.environ` (sketch), `main` cannot refuse under it without killing `record`, and `execute` then dies with "evidence covariate recorder exited early". The variable must cross exactly one boundary: executor → collector.

## 1. Where the seam lives; how "untouched when absent" is pinned

**Sampler (`scripts/sample_quiet_predicate_evidence.py`).** Only `main()`'s `collect` branch changes: `factory = ReplayRecorder if os.environ.get(REPLAY_ENV) else PowerRecorder; collect(args, recorder_factory=factory)`. `collect()` and `PowerRecorder` are untouched except one metadata key `recorder_kind: "powermetrics"`. `class ReplayRecorder(PowerRecorder)` overrides `__init__` only: `self.argv = [sys.executable, "-B", __file__, "_replay", <archived envelope dir>, str(path)]`, `metadata.recorder_kind = "replay"`, `metadata.replay = {source_plist_sha256, source_session_sha256}`. `start` (Popen, `journal_process("power")`, first-frame wait, ps tree), `request_stop` (TERM), `force_stop`, `finish` (parse, align, anchor) are inherited and run for real.

**Writer (`_replay` subcommand, same file).** Reads the archived plist once, splits on `\0`, reads `A_arch = session.json.power.anchor.first_sample_end_point_epoch_s`, computes `K = ceil(time.time() − A_arch)` (whole seconds), sleeps until wall `A_arch + K`, then writes frame i at monotonic `t0 + Σ elapsed_ns` with every `<date>` label shifted by exactly `K` s and every other byte identical; flushes per frame; exits 0 on SIGTERM (mid-frame if it lands there, which is what powermetrics does). Because the first write happens after `A_arch + K` and after the sampler's `pre_spawn`, and `first_parse` follows the write, the endpoint `A_arch + K` sits inside the stamp bracket; labels, rollovers and `elapsed_ns` are the archived ones, so the anchor resolves **bounded** and the full tail runs. `network_time_provenance(environ)` gains one branch: under `REPLAY_ENV`, a control record of schema `joulewise.network_time_control.replay.v1` yields `{"state": "replay_untoggled", "method": "replay_no_toggle_v1", …}`; absent the variable it stays `None` (refusal), exactly as today.

**Executor (`joulewise/quiet_predicate_campaign.py`).** `execute(plan, protocol, night_dir, *, controls=None)`; `controls = controls or PRODUCTION_CONTROLS` with `establish(night_dir)` = `establish_network_time_off`, `restore(night_dir)` = `restore_network_time`, `child_environment() = {}`, `kind = "powermetrics"`. `ReplayControls(archive_root)`: `establish` writes the replay-schema record (no `subprocess`), `restore` appends `on: {"replay": true}` and returns True, `child_environment() = {REPLAY_ENV: archive_root}`, `kind = "replay"`. `execute` merges `controls.child_environment()` into `env` (the collector's environment only) and writes `recorder_kind: controls.kind` into `evidence_outcome.json`. `campaign.main` refuses every command (`run`, `verify`, `record`, `refuse`) when `REPLAY_ENV` is in its own environment: "replay recorder variable set: the evidence chain never runs a replay", rc 2.

**Bench entry point (`scripts/bench_replay_start_drift.py`, new; NOT in `MANIFEST_PATHS`).** Builds a `NightPlan` (`plan_id = bench-replay-<utc>`, `receipt_class = DIAGNOSTIC_NO_PACK`, `custody_root` under `~/night-bench/`, never `~/night-custody/`), loads the tracked v2 protocol through `frozen_protocol` + `validate_protocol` (chain digest from the checkout), refuses if any `com.joulewise.night*` launchd label is loaded, then calls `execute(plan, protocol, night_dir, controls=ReplayControls(archive))` and writes `bench-replay.json` (§4). It never sets `os.environ`.

**Pins (production identical when absent).** R1 every existing `FrozenExecutorTests` case runs `execute` with no `controls` and stays green; one adds `assertNotIn(REPLAY_ENV, popen_env)` (counterfactual: inject the key unconditionally → FAIL). R2 sampler `main(["collect",…])` with the variable absent passes `recorder_factory is PowerRecorder`; set → `ReplayRecorder` (counterfactual: swap the default). R3 `campaign.main` under the variable → rc 2, `execute` not called, for all four commands (counterfactual at `489b0953`: runs). R6 `network_time_provenance` on a replay-schema record without the variable → `None` (counterfactual: accept unconditionally).

## Disagreements with the sketch

1. **No variable inside `execute`.** `controls=` is the in-process seam; the variable crosses only executor → collector via `controls.child_environment()`. Otherwise `campaign.main` cannot refuse under it (F2).
2. **Not byte-identical.** Constant integer-second label shift with the first write at `A_arch + K`; without it the anchor refuses and the tail is under-measured (F1). Record both digests and `K`.
3. **No forged OFF receipt.** A replay-schema control record, admitted by the sampler only under the variable, state `replay_untoggled`. The real `log show` attestation still runs — its wall cost is on the measured path.
4. **Harvest refusal belongs in `pilot_summary`**, not in the courier: the summary is what the harvest reads.
5. **Twelve plists, slot i ↔ envelope i**, not one plist twelve times (size varies 130–133 MB).
6. **Own PR after the transaction** (§3), not a rider.
7. **Bench refuses while any night agent is loaded.**
