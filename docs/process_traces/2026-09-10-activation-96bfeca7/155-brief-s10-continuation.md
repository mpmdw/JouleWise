The design:

1. **A separate, byte-pinned continuation artifact** — r6 stays live and byte-identical; no new acceptance generation; zero churn to campaign pins. File `configs/calibration/epoch_continuation_d079_r6_25g83.json` (NOT written by you — the tool writes candidates to `--out` outside configs/; the issued file lands in a later governed transaction), schema `joulewise.calibration_epoch_continuation.v1`, keys: `schema_version, continuation_id, decision_ids ["D-102"], acceptance_id, acceptance_file_sha256, acceptance_derivation_sha256, continued_identity_epoch {the six IDENTITY_EPOCH_FIELDS}, ruling {channel "directive issue 316", d102_addendum_date, authority "owner"}, rule {level_screen_s, operative_bracket_screen_s, m_minimum 6, source "ratified_operatives of the acceptance"}, evidence {ledger {ledger_schema, head_sequence, head_digest}, session_id, session_kind "derivation", session_state, declared_slots, slots [12 × {slot, attempt_id, content_id, manifest_sha256, instrument_evidence_sha256, disposition, anchor_v3_resolved, anchor_v3_detail, b_fiducial_s}], acknowledged_attempt_ids, m, retained_min_s, retained_max_s, retained_range_s}, verdict "pass", candidate_not_issued (marker), derivation_sha256` (canonical sha of every other key, the acceptance's `_canonical_sha256` recipe). Registry `EPOCH_CONTINUATION_REGISTRY: dict[continuation_id, {path, relative_path, file_sha256}]` in `calibration_bracketing.py` mirroring `ISSUED_ACCEPTANCE_REGISTRY`; empty of issued entries in this PR (tests register fixture continuations by monkeypatching the registry the way the acceptance tests do — find that pattern).

2. **One loader notion: the epochs an acceptance JUDGES.** New module `joulewise/calibration_epoch_continuation.py` with `load_epoch_continuations(acceptance_artifact, ledger_snapshot, *, registry=EPOCH_CONTINUATION_REGISTRY) -> tuple[Continuation, ...]` returning only continuations that: authenticate byte-for-byte against the registry pin; carry no `candidate_not_issued` marker; have `verdict == "pass"`; name THIS acceptance id AND its file sha AND its derivation sha (all three equal to the loaded artifact's); whose `continued_identity_epoch` differs from the acceptance's in ≥ 1 field; whose `derivation_sha256` recomputes; and whose `evidence.session_id` the ledger snapshot contains as a TERMINAL derivation-kind session whose finalized attempt ids ⊇ `acknowledged_attempt_ids` with matching content ids (the cheap evaluate-time cross-check — a continuation citing a phantom session is refused with a named reason). Any failure → that continuation is ignored AND a refusal reason `calibration_epoch_continuation_invalid` is surfaced in the evaluation record (find the right place; it must not silently degrade to "stale"). `acceptance_judged_epochs(...)` = `(identity_epoch, *[c.continued_identity_epoch ...])`.

3. **Loader changes in `evaluate_calibration_bracket` (calibration_bracketing.py), four sites, cite each:**
   - Freshness (≈2046–2056/2106): observed identity fresh if it equals ANY judged epoch; when matched by a continuation, `freshness.basis = "epoch_continuation"` and the record carries `continuation_id`, the continuation file sha, `session_id`, `m`, `verdict`; `stale_fields` computed against the MATCHED epoch (so it is empty). Otherwise today's `calibration_acceptance_bound_stale`, unchanged.
   - Corpus doubling (≈2323–2332): counted PER judged epoch — the trigger fires when the valid captures of ANY single judged epoch reach the threshold (the adjudicated session's rows count toward the continued epoch's tally). Never pool across epochs.
   - Range expansion (≈2334–2344) and systematic failure (≈2347–2354): evaluated over rows of every judged epoch, EXCLUDING exactly `acknowledged_attempt_ids` of matched continuations (those rows were judged under r6 by the equivalence rule and enter no trigger). Every other 25G83 row — including future derivation-kind sessions — participates exactly as 25F84 rows do today.
   - Operatives, screens, corpus, the artifact's `triggers` vocabulary (validated as an exact set ≈797–805): UNTOUCHED.
