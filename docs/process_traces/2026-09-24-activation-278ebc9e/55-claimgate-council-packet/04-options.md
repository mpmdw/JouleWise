# Mechanisms for council comparison (unranked)

**Operating characteristic** means the observed admission, miss, false-alarm, or interval-coverage rate under a specified generating model. The existing grid tests the current evaluator and one proposed night-equivalence rule; it does not test the other mechanisms below (`docs/process_traces/2026-09-24-activation-278ebc9e/19-desk-simulations/README.md:13-27,69-71`). Costs below are implementation surfaces inferred from the named code and registration seams, not measured effort.

| Mechanism | What its rule would establish, conditional on a valid interval/model | Measured characteristic and implementation surface |
|---|---|---|
| Minimum-effect test on confidence bounds | Requiring the lower bound on the registered signed magnitude to exceed a physically matched F would support a **minimum** effect at that interval's coverage level; a point-only comparison does not make that statement. This is a possible redesign of the current strict point test (`joulewise/analysis_engine/claims.py:343-344`; `docs/decision_log.md:11291-11303`). | Not simulated. It needs a ruled estimand/floor unit match, interval construction, adjusted test convention, and claim-artifact changes; current intervals and floor metadata enter `evaluate_claim` already (`joulewise/analysis_engine/claims.py:258-272,282-323`). |
| TOST with a physically sized margin | TOST (two one-sided tests) can support a mean lying inside a predeclared physical tolerance if its interval and dependence assumptions hold. Production `tost_v1` additionally requires both intervals inside the margin and adjusted rejection (`joulewise/analysis_engine/estimators.py:251-279`; `joulewise/analysis_engine/claims.py:346-368`). | At diagnostic 4σ, δ=0 admission is 0.052 across claim cells (`docs/process_traces/2026-09-24-activation-278ebc9e/19-desk-simulations/README.md:40-48`). The proposed night rule at Δ=3.5σ, old n=17/m=12 has 0.002–0.013 no-change false FAIL, but misses 88.2–93.0% of ×4 variance changes (`docs/process_traces/2026-09-24-activation-278ebc9e/19-desk-simulations/equivalence_replacement.md:13-30`). Cost includes freezing physical units and corpus membership and adding an authenticated production rule (`docs/process_traces/2026-09-24-activation-278ebc9e/19-desk-simulations/equivalence_replacement.md:28-32`). |
| Block bootstrap interval that preserves dependence | Resampling whole parent blocks/envelopes can retain observed within-cluster dependence; its coverage still requires a suitable count and treatment of night-level shocks. AP-5M v5 proposes paired resampling of problem IDs and energy parent/envelope clusters, with exact nesting and power validation open (`docs/process_traces/2026-09-24-activation-278ebc9e/52-ap5m-v5-draft/01-ap5m-draft-v5.md:47-49,57-61`). | Not simulated. The current metrology 95% interval covers 0.556–0.565 across δ slices, while expanded decision coverage is 0.948–0.951 (`docs/process_traces/2026-09-24-activation-278ebc9e/19-desk-simulations/README.md:40-46`). Cost is estimator/replicate design, cluster identity in artifacts, and fresh coverage/power simulation (`docs/process_traces/2026-09-24-activation-278ebc9e/52-ap5m-v5-draft/01-ap5m-draft-v5.md:61`). |
| Hierarchical or explicit shared-shock model | A model with old/new night effects would distinguish within-night sampling scatter from between-night movement if enough independent nights identify that term. The desk generator draws a new shock for each equivalence night (`docs/process_traces/2026-09-24-activation-278ebc9e/19-desk-simulations/README.md:13-15`; `docs/process_traces/2026-09-24-activation-278ebc9e/19-desk-simulations/sim.py:202-215`). | Not simulated as an admission rule. The proposed ordinary 90% night-difference interval covers only 0.335–0.633 under the tested models (`docs/process_traces/2026-09-24-activation-278ebc9e/19-desk-simulations/equivalence_replacement.md:19-30`). Cost is an identifiable multi-night design, fitted-model validation, and a new registered rule (`docs/process_traces/2026-09-24-activation-278ebc9e/19-desk-simulations/equivalence_replacement.md:28-32`). |
| Separate physical floor condition | Keep F as a same-estimand instrument condition alongside a statistical direction/equivalence test. This preserves O-21's strict `|estimate|>F` and the separate anchor interval role; it alone does not turn a point estimate into a lower-bound minimum-effect claim (`docs/process_traces/2026-09-24-interactive-02a24110/01-ed-rulings-harvest-and-reply-miss.md:41-44`; `docs/decision_log.md:11291-11303`; `joulewise/analysis_engine/claims.py:343-344`). | Existing gate: 1.000 missed at 2σ and 0.840 at 5σ in the desk grid (`docs/process_traces/2026-09-24-activation-278ebc9e/19-desk-simulations/README.md:40-48`). Cost centers on matching F to the estimate class and units, open for AP-5M's log budget-pair contrast (`docs/process_traces/2026-09-24-activation-278ebc9e/52-ap5m-v5-draft/01-ap5m-draft-v5.md:65-69`). |
