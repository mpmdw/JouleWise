## Process and lifecycle

The chain's **own payload step** spawns one binary/process whose argv contains `km003c_window_reader` and an output path under that night's payload directory. The process is a descendant of the night chain, never of a `claude`, `codex` or `t3` process. The chain starts it immediately after its own start marker and before settling, waits for a first valid sample with a bounded timeout, and leaves it ON for the **whole exclusive window**, including settle, idle brackets and every envelope. At the normal chain close, or on chain termination, a trap sends one stop signal, waits a bounded interval, then records exit status; a timeout uses the existing process-group cleanup and records `reader_stop_unproven`. The reader never sends a control command that changes power supply or model behavior; only `Connect`, repeated `GetData(ADC)` and `Disconnect` as in the archived probe. Poll target is 0.5 s; exact achieved gaps are retained, never silently interpolated. For G2-a night 1 the reader is **passive only**: no on/off segments and no change to registered G2-a inputs, schedule or refusal. Its presence on G2-a is conditional on all four R-ORDER(1) conditions; otherwise G2-a runs without it and the logger moves to calibration night 2.

## Sample and sealed import

One UTF-8 JSONL file, append-only while recording, one object per receipt:

```json
{"schema":"joulewise.km003c_sample.v1","seq":17,"host_receipt_epoch_ns":1790056832212000000,"host_receipt_monotonic_ns":1234567890,"transport":"bulk","device":"KM003C","tid":18,"vbus_uV":27552600,"ibus_uA":433600,"power_W":11.947,"temp_C":35.1,"rate_idx":0,"flags":0,"status":"ok"}
```

The illustrative values are from the archived example, not a prospective calibration. Preserve raw integer ADC fields and host receipt timestamps; `power_W=(vbus_uV×ibus_uA)/10^12`. Include `transport`, VID/PID, device/firmware identity if readable without changing device state, sequence, transaction ID, response length and flags. Non-OK/timeout rows carry error code and receipt time but no invented power. Also preserve a sidecar with reader version/source SHA-256, chain SHA-256, host boot session, first/last receipt, sample counts, gap histogram, exit reason, and every segment-marker clock mapping. The **host receipt** time is authoritative; the KM003C has no trusted shared clock in this design. Keep both epoch and monotonic host receipt clocks to detect jumps; event alignment uses epoch only after checking the monotonic map. R-Q2's exact 2 s end trim applies in reduction, never by modifying raw rows.

At chain completion, fsync and close the raw JSONL; compute SHA-256 on the closed bytes; import by creating a new file in the night's payload custody with exclusive creation, byte-for-byte copy, and a second digest verification. Record source and imported digest, length and relative payload path in the payload manifest. Once sealed, never append, normalize or overwrite the imported log. A missing or mismatched digest, nonmonotone sequence/receipt clock, unsupported ADC record, or material gap is reported with its exact mechanism. The logger's error may make the **calibration analysis** unavailable under its registration, but must not turn the night's existing refusal into success or add a new G2-a refusal; the driver remains sole owner of night admission/abort (`joulewise/night_gate.py:200-247`). The chain records a diagnostic even if the logger fails and continues according to the preexisting night's rule. Any intended failure mode that would alter G2-a admission is a fresh cold-gate matter.
