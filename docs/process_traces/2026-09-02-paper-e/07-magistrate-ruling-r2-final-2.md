# Magistrate ruling R2-final-2 (supersedes R2 in file 03a), 2026-09-03 21:40 PDT

The Opus counter-review (file 06, S-1) shows the R2 mechanism was mis-stated: the issued median record width (DG-071, 120.9186 ms) is slightly SHORTER than the issued phase duration (DG-070, 0.121034145 s), so "sampling records wider than the phase" is false for the typical record. The correct mechanism, stated without new numbers: a third overlap requires one sampling record to lie entirely inside the phase; the phase is only barely longer than a typical record, so the alignment window that allows containment is very narrow for a median-width record and widens only for records at the short end of the issued width spread (the IQR). Alignment, not width alone, denies the third overlap in most phases; a shorter middle record makes containment easier, not possible. The figure's upper row shows records of about the SAME width as the phase, misaligned so the phase straddles a boundary and overlaps two; the lower row shows a shorter middle record contained by the phase (three overlaps). Captions say so. No arithmetic on issued values is printed (no subtraction result); "close to" is deleted.
