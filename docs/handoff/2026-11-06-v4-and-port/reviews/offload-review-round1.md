## BLOCKER

Step 8's tests, the Python KEEP asserts and the cmp checks (lines 676–703) are separate commands before `rm -rf -- "$JW_SRC"`. They only stop the deletion if `set -euo pipefail` from step 2 is active in the same Terminal. Step 8 usually runs in a fresh Terminal, where jw_disk_check is undefined and the floors are no-ops. Scenario: a fresh Terminal with JW_SRC mistyped as a KEEP root; the asserts print errors and rm -rf still deletes it. Comments: with zsh defaults (no interactivecomments) a pasted `# comment` runs as a command; with extendedglob it gives `bad pattern: #`; with set -e it exits on step 2 line 107. Fix: step 2 writes $JW_OP/env.zsh (setopt interactivecomments errexit nounset pipefail extendedglob noclobber; exports; jw_disk_check). Every later block sources it or runs as `zsh -f -euo pipefail step.zsh`. Replace the step-8 shell block with one hashed program (python3.13 -I -B delete_root.py) that does every check and then shutil.rmtree, exiting nonzero with no deletion if anything fails.
