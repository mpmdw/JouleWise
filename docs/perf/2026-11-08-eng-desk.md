## What changed

The actual per-window entry is `scripts/align_v4_session.py desk`, which uses
`align_pilot_session.desk` and its v4 addendum. The separate thermal entry is
`scripts/align_v4_thermal_desk.py`. `run_night` produces the terminal custody
record; the desk requires `custody/night/result.json`. Extraction finishes
before `harvest_b6_session.py` can archive/compress anything. That subprocess,
its refusals, independent checks and finalization are unchanged.

- One reusable process pool, explicit spawn, 1–8 workers (default 1), at most
  `2*workers` submitted tasks. Member results and exceptions are consumed in
  roster order. No cross-run cache or completion-order floating-point sum.
- Pilot member reads and v4 thermal member reads run in bounded workers.
  The independent instrument, sampling and residual reductions also share the
  pool, with results consumed in the original stage order. Publication is serial.
- Thermal extraction shares one decoded immutable episode with enrichment,
  eliminating its second bundle decode. No estimator, threshold or roster changed.
- `--profile NEW.json` records stage wall/CPU and per-task timings separately
  from scientific output. `pilot.total` and `pilot.extra_checks` include child
  stages; do not add inclusive rows together. Worker startup/shutdown and IPC
  are included in total elapsed time; task CPU excludes worker startup.
- `scripts/align_v4_record_desk.py` is a laptop entry without host admission,
  power-mode, measurement launch or harvest commands. It reads a descriptor
  from a full Git commit SHA, authenticates an explicitly supplied local export
  before and after replay, replaces original host locators, and atomically
  publishes to a new output directory. It rejects missing/changed/unlisted
  files, symlinks, escaping paths and nonterminal records. `REPLAY.json` records
  provenance; timing/worker metadata stay outside PILOT/desk output.

## Profile and measured synthetic equality

Profile first: eight original pilot summaries took **0.0883 s**, and eight
original thermal-read/enrichment pairs **0.0946 s** under cProfile. Bundle
decoding accounted for **0.115 s of 0.171 s** profiled execution time,
24 decodes in total. Shared thermal decoding reduces that count to 16.

The reproducible benchmark builds 18 fake endpoint bundles, each with 12,000
or 48,000 synthetic CSV power samples, plus one absent and one corrupt member. It loads
the original serial desk source directly from the base Git objects. Both runs
below compare **PILOT.json, desk.json and complete stdout byte for byte** against
that original implementation: 10,054,196 output bytes in the 12,000-sample case
and 10,054,052 in the denser case, all equal.

## Laptop handoff

The audit did not specify an existing portable export layout. The new interface
therefore requires an explicit layout plus a complete local evidence tree.
A summary-only committed record cannot reconstruct raw member checks.

Export the terminal session/plan, closed member bundles, custody journals and
meter streams, kit collection plan, registration inputs/receipts/fixtures, and
the existing harvest archive into one dedicated tree. Keep the original bytes;
the laptop uses relative layout roots instead of modifying their locator text.
Do not include models, caches, unrelated windows or symlinks. Example layout:

```json
{
  "session": "session",
  "measurement_root": "measurement",
  "registration_dir": "measurement/configs/campaigns/align_v4/registration",
  "runs_root": "runs",
  "custody_root": "custody",
  "plan": "plan.json",
  "targets": {"EXACT_RUN_ID": [["gross_request"], ["idle_subtracted_request"]]}
}
```

`targets` must contain the **actual** pack-derived target-precheck paths per
roster member, including explicit empty lists where appropriate; the example
paths are illustrative. If the source session had a pack root, replay refuses
an absent or incomplete target map. This keeps standalone diagnostic defaults
from replacing pack-specific harvest targets.

After an explicitly authorized export, author its descriptor, commit that small
file in the window record, and transport the authenticated export separately:

```sh
python3.13 -B scripts/align_v4_record_desk.py \
  --describe layout.json --inputs LOCAL_EXPORT --output record-descriptor.json
python3.13 -B scripts/align_v4_record_desk.py \
  --commit FULL_RECORD_COMMIT_SHA --record PATH_IN_REPOSITORY/record-descriptor.json \
  --inputs LOCAL_EXPORT --output NEW_REPORT --workers 2 --profile NEW_TIMINGS.json
```

Replay preserves canonical archive/PILOT/desk files, writes `PILOT.json`,
`desk.json` and `REPLAY.json` outside the export, and returns 2 for an incomplete
instrument report. It is the existing `--no-harvest` inspection semantics with
authenticated relocation: it does **not** establish that upstream harvest
succeeded, replace required independent arithmetic, authorize the next arm, or
replay optional cross-pilot bundle comparisons. The thermal manifest entry still
supports portable `--compare-session PILOT.json` inputs for K-session reading.
