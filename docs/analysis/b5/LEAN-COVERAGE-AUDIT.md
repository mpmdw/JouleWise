- `STRUCTURE_NUMBER`, the battery discharged-energy exemption, and much of `NEG8_INTERNALS` contain omissions listed in section 2 ([C:3502](../../../scripts/compare_b5_recompute.py), [C:3516–3517](../../../scripts/compare_b5_recompute.py), [C:3691](../../../scripts/compare_b5_recompute.py), [C:3706–3715](../../../scripts/compare_b5_recompute.py)).
- `CONSTANT` covers per-token denominator, planned reference counts, planned/complete-observation sampling counts; `IDENTITY_NUMBER` covers attempt/position/ledger identities ([C:3499](../../../scripts/compare_b5_recompute.py), [C:3518](../../../scripts/compare_b5_recompute.py), [C:3547](../../../scripts/compare_b5_recompute.py), [C:3661](../../../scripts/compare_b5_recompute.py), [C:3689](../../../scripts/compare_b5_recompute.py), [C:3701](../../../scripts/compare_b5_recompute.py), [C:3716](../../../scripts/compare_b5_recompute.py), [C:3783](../../../scripts/compare_b5_recompute.py)). Some are stored inputs/constants rather than estimators; observed_complete_n is not independently recounted by the lean kept-n calculation ([I:2714–2718](../../../scripts/independent_recompute_b5.py)).
- `uncovered-null-by-name` covers registered null J/token/equivalence/ratio-estimand/characterization fields and absent trigger objects; these are not omitted finite estimates ([C:3543](../../../scripts/compare_b5_recompute.py), [C:3604–3610](../../../scripts/compare_b5_recompute.py), [C:3712–3713](../../../scripts/compare_b5_recompute.py), [C:3773–3774](../../../scripts/compare_b5_recompute.py)).
- First-match ordering matters: the later structural rule mentioning attempt_count/count and G10/redraw_cycles does **not** exempt their earlier `count`/`outcome_word` rules ([C:3765–3777](../../../scripts/compare_b5_recompute.py); actual comparisons [C:2636–2651](../../../scripts/compare_b5_recompute.py)).

**“624” is historical, not this audit's current census.** [RS:340](../../../RUN_STATE.md) reports a full-size synthetic snapshot with 841 leaves, 217 compared and 624 uncovered; [RS:342](../../../RUN_STATE.md) requires hand checking any uncovered quantity the paper prints against lean output. Current code distinguishes numeric named exemptions from text/identity, requires expected keys, and reports `uncovered_numeric`/`named_exemptions`; it does not turn exemptions into comparisons ([C:3471–3507](../../../scripts/compare_b5_recompute.py), [C:3913–3986](../../../scripts/compare_b5_recompute.py)). For a quantity absent from lean output, that hand check needs another derivation/source check; it cannot compare two nonexistent values (section 2).
