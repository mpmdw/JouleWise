## The contract question

When a measurement window closes as salvage under the ratified
third-failure rule (D-087) with a §10-quarantined member occurrence that
has ZERO surviving bundles and CAN NEVER receive its required
replacement (the window is over), what is the ratified terminal
whole-window-verdict semantic for that occurrence?

## Candidate semantics (the gate may propose variants)

- **S1 — fail-closed terminal refusal (the audit's minimal repair):**
  zero surviving occurrences without an exact selected supersession is
  terminal `whole_window_campaign_membership_unresolved`, regardless of
  declaration count; presence check added to the single-declaration
  branch. Consequences: uniform machinery; windows A and B remain FAILED
  permanently; C2/C4 re-collect in a future window; a recurrence in any
  future salvage-closed window likewise fails the whole window.
- **S2 — ratified non-fatal exclusion:** a §10-quarantined occurrence
  with zero surviving bundles in a D-087 salvage-closed window becomes a
  DEFINED terminal disposition (recorded, exhaustively evidenced,
  exclusion listed in the verdict row), membership resolves over the
  surviving members, and the remaining verdict gates run normally.
  Consequences: window B would plausibly PASS a re-evaluation run after
  the repair lands (bracket already passed; supersession consumable;
  NEG-8 resolvable) — i.e., THE REVERSAL CASE: an issued FAILED verdict
  would be superseded by a later governed re-evaluation under amended
  contract; the conditions licensing that re-evaluation must be part of
  the ruling if S2 is chosen. Window A remains FAILED either way.

## Considerations on the record (both directions, no weighting)

- For S1: fail-closed uniformity; no risk of selective-loss laundering
  (a window that sheds failing members then salvage-closes must not
  thereby improve its own verdict); D-087's third-failure rule exists
  precisely because repeated failures signal an unquiet environment;
  the no-outlier-deletion doctrine's spirit.
- For S2: the missing member was never measured — nothing observed is
  being deleted; exclusion is visible, recorded, and bounded (at most
  the salvage dangler); S1 destroys otherwise-clean whole-window
  evidence (B's bracket passed) over a slot whose absence the §9 gates
  can already see; per-cell minimum-n gates (`minimum_claim_n`) exist
  downstream and continue to govern what any cell can license; the
  environment-correlated missingness argument applies to LAUNCH
  admission, not to the measurand of surviving members, each of which
  passed its own admission gates.
- Hazard for S2 the refuter should press: does non-fatal exclusion
  create an incentive gradient (operators tolerating failures knowing
  salvage still passes)? Does the D-087 closure signal lose meaning if
  the closed window can still fully license claims? Should S2 require
  a cap (e.g., valid only when the window used its failure budget on
  ADMISSION-class failures, never measurement-anomaly failures)?
- The recorded supersession discard (fact 2) is repair-mandatory under
  EITHER semantic: a valid unrelated supersession being destroyed by an
  unsatisfiable sibling group is not a candidate behavior anyone
  defends.
