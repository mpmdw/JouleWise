## Conditional bound for the integration fixture

The only numerically bounded operating profile in the decision table is **invented**. It uses a stable clock, 0–60 seconds from T to R, and at most 1,100 seconds from T through the actual delay sample including dwell and journal. After release it allows ten seconds for dispatch, twelve seconds of work outside each cap before that attempt's start decision, and the balance of 100 seconds after the last cap. Other intervening steps have zero additional elapsed time in this model. The child's own batch check occurs at most 100 seconds into the soak cap. Together with dispatch that fits inside the 150-second difference between parent and child look-ahead. The fixtures allow 180 seconds in total for proven restore/close and 190 for successful outer clearance. These joint limits are inputs to the example. The source code supplies the stage order, tests, configured caps and absolute cutoffs.

These bounds cover continuous offsets. For a fixed set of half-open windows, the earliest clear interval start at or after E is nondecreasing in E, including at the jump one instant after an end-touch. Taking the latest selector time, advancing through each full stage, reapplying the relevant delay, and reserving all attempts therefore bounds every earlier permitted path in this profile. Redos use the same cap and start rule. The possible runner re-plans cover [T,T+60+W) as a union; if that union meets the passed window, admission under that start range is unproven.
